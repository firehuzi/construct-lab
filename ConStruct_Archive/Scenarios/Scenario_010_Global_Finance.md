## 一、场景概述

全球金融体系正进入一个“结构性断裂”的时期。2026年，全球经济增速预计放缓至2.5%，为新冠疫情以来最低水平，若能源供应中断不能短期恢复，增速可能进一步降至1.3%。全球债务总额攀升至接近**353万亿美元**的历史新高，占全球GDP的305%。通胀粘性迫使全球央行从“等待降息”转向“保留加息选项”，货币政策步入高波动新周期。

与此同时，以美元为核心的国际货币体系面临新的挑战，**去美元化**正在从话语变成行动。从2020年到2026年，美元在全球储备中的份额预计下降近14个百分点，相当于各国央行总共减持了大约3.2万亿美元的美元资产。人民币国际化加速推进，数字人民币跨境服务正式启动。世界经济论坛2026年报告指出，2025-2026年已成为全球贸易和金融的转折点，政府以“经济治国术”干预市场的规模在现代史上未曾见过。

全球金融体系正在从“美国主导的单极秩序”走向**“多极碎片化”**的新阶段。

**场景边界定义：**
- 地理范围：全球——美国、中国、欧洲、新兴市场
- 行为范围：货币政策、债务管理、储备货币竞争、跨境支付系统、资本流动、金融制裁
- 时间范围：2026年（当前）— 2030年（结构性转折窗口）


## 二、核心矛盾

### 矛盾一：美元霸权 vs 去美元化

美元体系的核心矛盾是：**美国需要美元保持全球储备货币地位来融资其不断膨胀的债务，但美国的债务膨胀本身正在侵蚀美元的信誉。**

| 维度 | 数据 | 含义 |
|------|------|------|
| 美元储备占比 | 2020-2026年下降近14个百分点 | 各国央行减持约3.2万亿美元美元资产 |
| 美元指数 | 2025年4月以来维持在97-100区间震荡 | 美元地位面临结构性压力 |
| 全球基金经理调查 | 46%受访者认为美元被高估 | 看空共识持续维持在历史高位 |
| 黄金 | 74%央行预计未来5年美元储备占比下降，黄金储备可能增加 | 黄金是美元最强劲的“挑战者” |

美国联邦政府债务规模的急剧膨胀，是美元信用风险上升的核心矛盾所在。摩根士丹利警告，特朗普政府政策可能加速全球去美元化进程。

### 矛盾二：债务螺旋 vs 政策空间

353万亿美元的全球债务和305%的债务/GDP比率意味着：**利率的微小上升都会产生巨大的利息成本。** 而通胀粘性正在迫使央行维持高利率甚至加息。

| 指标 | 数值 | 含义 |
|------|------|------|
| 全球债务总额 | 353万亿美元（历史新高） | 债务/GDP 305% |
| 新兴市场债务 | 36.8万亿美元（历史新高） | 新兴市场债务比率稳步上升 |
| 成熟市场债务 | 占全球债务主体 | 债务比率呈下降趋势 |
| IMF全球金融稳定风险 | “已处于较高水平” | 中东战事、通胀压力、金融环境收紧三重挑战 |

IMF指出，公共债务和私人债务高企、再融资风险、银行-主权关联继续使债券市场在某些国家变得脆弱。

### 矛盾三：金融碎片化 vs 全球化惯性

世界经济论坛报告指出，2025-2026年政府以“经济治国术”干预市场的规模在现代史上未曾见过。金融碎片化正在从“竞争对手之间”扩展到更广泛的结构性转变。

| 维度 | 内容 |
|------|------|
| 贸易壁垒 | 各国以意想不到的方式提高壁垒 |
| 资本流动 | 跨境证券投资主要由非银行金融机构中介 |
| 金融制裁 | 美元武器化加速了替代支付系统的建设 |
| 供应链金融 | 地缘政治正在分裂全球供应链金融体系 |

### 矛盾四：通胀粘性 vs 增长放缓

世界银行预测2026年全球经济增速为2.5%，为疫情以来最低。但通胀依然顽固——美联储将2026年PCE预期从2.7%大幅上调至3.6%。这种“滞胀”倾向是货币政策最大的两难。

| 指标 | 数值 |
|------|------|
| 全球经济增长（世界银行） | 2.5%（2026年） |
| 全球经济增长（IMF） | 3.1%（2026年） |
| 美国PCE通胀预期（美联储） | 3.6%（2026年） |
| 美国政策利率 | 3.50%-3.75%（连续第四次维持） |
| 美联储加息预期（18名官员中） | 9人预计2026年底前至少加息一次 |


## 三、参与主体诊断

### 美国（US）——“被债务锁住的体系主导者”

| 维度 | 诊断 |
|------|------|
| 构型 | 交易式 |
| 在该场景中的角色 | **被债务锁住的体系主导者**——美元体系仍是全球金融的锚，但债务正在消耗其政策空间 |
| 核心目标 | 维持美元霸权、控制通胀、管理债务可持续性 |
| 关键约束 | **债务/GDP >120% + 利息支出超过国防预算 + 去美元化加速** |

**2026年最新动态：**

**美联储进入“沃什时代”：**

2026年6月18日，新任美联储主席凯文·沃什在其上任后的首场FOMC会议上，宣布废弃“前瞻指引”机制，强调决策将回归对实时数据与金融市场价格的直接依赖。美联储宣布连续第四次维持联邦基金利率目标区间3.50%至3.75%不变。最新点阵图显示，18名官员中有9人预计2026年底前至少加息一次，其中6人主张累计加息50个基点或以上；而在3月的预测中，无一人预计年内需要加息。仅有1名官员预计今年会降息。

美联储将2026年PCE通胀预期从2.7%大幅上调至3.6%，核心PCE预期亦上调至3.3%。沃什宣布围绕货币政策对外沟通、资产负债表政策、数据渠道运用与依赖体系、劳动生产率与就业问题、通胀分析框架五大核心领域成立专项工作组。

**债务压力：**

国际金融协会（IIF）报告指出，2026年初的债务增长主要由**美国政府增加举债推动**。美国国债需求出现疲态，投资者开始出现分散配置、降低对美国公债依赖的迹象。

**框架定位：** 美国正在从“确定性锚”变成“不确定性源”。美联储的政策转向（从降息预期→加息预期）正在重塑全球金融市场的定价逻辑。债务正在消耗政策空间，通胀正在侵蚀美元购买力，去美元化正在侵蚀美元霸权。

### 中国（CN）——“替代金融基础设施”的构建者

| 维度 | 诊断 |
|------|------|
| 构型 | 天下型 |
| 在该场景中的角色 | **替代金融基础设施的构建者**——通过数字人民币、CIPS和金砖支付系统，构建美元体系的“平行轨道” |
| 核心目标 | 推动人民币国际化、降低对美元体系的依赖、建立替代性金融基础设施 |
| 关键约束 | **人民币在全球储备中占比仍低（约3%）+ 资本账户管制 + 美元体系的网络效应** |

**2026年最新动态：**

**数字人民币跨境支付正式启动：**

2025年6月，中国人民银行行长潘功胜宣布在上海设立数字人民币国际运营中心。2026年，该中心升级为“数币达”（Cross-border e-CNY Transfer Services，简称CBETS）跨境结算综合服务平台，并启动品牌化运作。

2026年6月，数字人民币国际运营中心与包括工银亚洲、渣打中国在内的首批26家机构签署CBETS直接参与者协议，业务可覆盖新加坡、老挝、泰国、阿联酋、卡塔尔、巴西，以及香港、澳门等国家和地区。境外参与者可通过香港接入点一点接入。

工商银行、交通银行等机构分别发布了数字人民币跨境电商、“外包内用”等解决方案，持续丰富跨境数字人民币应用生态。

**人民币国际化的结构性挑战：**

根据美银美林2026年3月发布的全球基金经理调查，46%的受访者认为美元被高估。但人民币在全球储备中的占比仍远低于美元（约3% vs 57%）。资本账户管制和美元体系的网络效应是人民币国际化的核心约束。

**框架定位：** 中国正在构建美元体系的“平行轨道”。数字人民币国际运营中心是中国金融突围的核心工具。但这不是“取代美元”——这是在构建一个“备用系统”。

### 欧洲（EU）——“规则制定者”的防御性整合

| 维度 | 诊断 |
|------|------|
| 构型 | 整合式 |
| 在该场景中的角色 | **防御性整合者**——通过强化欧元和金融监管，应对美元体系的不确定性和金融碎片化 |
| 核心目标 | 强化欧元国际地位、维护金融稳定、应对美国政策外溢 |
| 关键约束 | **欧元区财政不统一 + 经济增长乏力 + 内部协调成本高** |

**2026年最新动态：**

2026年6月18日，英国央行预计按兵不动，维持基准利率于3.75%不变。欧元区和日本同步加息，全球货币政策的底色正在悄然翻转。

在陆家嘴论坛上，全球金融治理改革成为焦点。新兴市场国家和全球南方在全球经济中的权重持续提升，国际金融治理改革再度成为全球关注的焦点。

**框架定位：** 欧洲在全球金融体系中处于“守势”——既无法挑战美元霸权，也无法完全脱离美元体系。欧洲的策略是通过强化欧元和金融监管来“防御”美元体系的外溢效应。

### 新兴市场——“债务陷阱”与“战略自主”之间

| 维度 | 诊断 |
|------|------|
| 构型 | 混合型（各国差异极大） |
| 在该场景中的角色 | **债务承压者+战略自主探索者**——债务攀升但在寻求美元之外的替代方案 |
| 核心目标 | 管理债务风险、寻求替代融资渠道、减少对美元体系的依赖 |
| 关键约束 | **债务/GDP比率稳步上升+ 资本外流风险 + 本币贬值压力** |

**2026年最新动态：**

新兴市场债务攀升至36.8万亿美元的历史新高。本期债务率涨幅居前的经济体为挪威、科威特、中国、巴林、沙特阿拉伯，五国债务占GDP比重增幅均超30个百分点。

IMF警告，公共债务和私人债务高企、再融资风险使债券市场在某些国家变得脆弱。

### IMF/世界银行——“被边缘化的秩序守护者”

| 维度 | 诊断 |
|------|------|
| 构型 | 整合式衰退版 |
| 在该场景中的角色 | **被边缘化的秩序守护者**——拥有全球金融稳定的职责，但治理结构被冻结在1944年 |
| 核心目标 | 维护全球金融稳定、提供危机救助、推动经济治理改革 |
| 关键约束 | **美国否决权 + 新兴市场代表性不足 + 资金规模有限** |

**2026年最新动态：**

IMF的2026年4月《全球金融稳定报告》指出，金融稳定风险已处于较高水平。报告强调中东战事、通胀压力、金融环境收紧等多重挑战。IMF强调，跨境证券投资流动主要由非银行金融机构担任中介。IMF还警告，公共债务和私人债务高企、再融资风险以及银行-主权关联继续使债券市场变得脆弱。

世界银行近日发布的《全球经济展望报告》指出，2026年全球经济增速预计放缓至2.5%，若能源供应中断不能短期恢复，增速可能进一步降至1.3%。

## 五、路径推演

### 路径A：债务螺旋+滞胀——全球金融体系的“慢性衰竭”（概率：40-45%）

**核心叙事：** 全球债务持续攀升，通胀粘性迫使央行维持高利率，经济增长放缓。各国陷入“债务螺旋”——借新债还旧债、利息成本吞噬财政空间、增长乏力无法支撑债务可持续性。

**条件：**
- 全球债务/GDP维持在300%以上
- 通胀无法回落至目标区间（美国PCE >3%）
- 全球经济增长持续低于3%
- 货币政策在高利率与降息之间摇摆

**终局状态：** 全球金融体系进入“慢性衰竭”——债务不断积累、增长持续低迷、政策空间不断收窄。不是一次性危机，而是长期的“温水煮青蛙”。

### 路径B：去美元化加速——美元体系“慢崩盘”（概率：20-25%）

**核心叙事：** 去美元化从话语加速为行动。各国央行持续减持美元资产，数字人民币和金砖支付系统开始实质性分流美元交易。美元体系进入“慢崩盘”——不是一夜之间崩溃，而是持续十年的结构性衰落。

**触发条件：**
- 美元储备占比跌破50%
- 数字人民币/金砖支付系统交易量突破临界点
- 美国债务/GDP突破150%
- 美联储信誉因政治干预受损

**终局状态：** 全球货币体系从“美元单极”走向“多极共存”——美元仍是主要储备货币，但不再是唯一主导。人民币、欧元、黄金形成新的平衡。

### 路径C：全球金融危机——债务清算（概率：15-20%）

**核心叙事：** 某个触发点（如美国国债拍卖失败、某新兴市场主权违约、影子银行挤兑）引爆全球金融体系的结构性脆弱性，导致系统性危机。

**触发条件：**
- 美国国债需求崩溃（IIF已观察到分散配置迹象）
- 中东战事导致能源价格飙升、通胀失控
- 某个新兴市场大国（如印度、巴西）发生主权债务危机
- 全球债务/GDP突破320%

**终局状态：** 全球金融体系的“大清算”——债务重组、资产价格暴跌、经济深度衰退。类似于2008年金融危机但规模更大，因为全球债务是2008年的数倍。

### 路径D：数字人民币突破——平行金融体系成型（概率：10-15%）

**核心叙事：** 数字人民币跨境支付体系（CBETS）在金砖国家、“一带一路”沿线国家快速扩展，形成美元体系的“平行轨道”。人民币在跨境贸易结算中的占比突破15%，成为全球第三大支付货币。

**触发条件：**
- CBETS覆盖50+国家
- 金砖国家支付系统与数字人民币对接
- 中东石油贸易开始使用人民币结算
- 美元体系因制裁滥用而失去信任

**终局状态：** 全球金融体系出现“双轨制”——美元体系主导传统金融，人民币体系主导新兴市场贸易和投资。美国无法阻止这一进程，因为数字人民币的底层技术使其难以被制裁。

### 路径E：美元“数字化自救”——私人稳定币战略（概率：5-10%）

**核心叙事：** 华盛顿没有选择央行数字货币（CBDC），而是战略性地押注私人数字美元（稳定币）。通过GENIUS Act等立法框架，将私人稳定币纳入美国金融体系，构建“美国版数字美元”。

**触发条件：**
- 美国通过稳定币监管框架
- 主要稳定币（USDC、USDT）获得美联储背书
- 数字人民币在跨境支付中取得突破，迫使美国回应
