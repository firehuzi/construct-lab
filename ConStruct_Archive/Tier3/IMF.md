## 模块一：基础信息

| 字段 | 内容 |
|------|------|
| 主体名称 | 国际货币基金组织（IMF / International Monetary Fund） |
| 成立时间 | 1944年（布雷顿森林体系） |
| 成员国 | 190国 |
| **连续性类型** | **制度秩序型**——Identity="全球金融稳定的守护者+最后贷款人" |
| **构型** | **整合式（治理被冻结版）**——投票权=经济份额——但经济份额的调整远远落后于现实。美国拥有~16.5%投票权（可以否决重大决定），比利时+荷兰的投票权超过中国（2024年份额改革前） |

| **身份一句话** | 我是全球资本主义的消防员。当市场抛弃你、债权人追债、你的人民在街头排队买面包——我是唯一会接你电话的机构。但我接电话是有条件的——你必须按照我的处方改。这就是为什么全世界都恨我——但每次危机他们还是给我打电话。 |


## 模块二：IMF的悖论——条件性是力量，也是仇恨

**IMF不像世界银行（发放发展贷款）——IMF是做危机救援的。** 当一个国家面临国际收支危机（无法支付进口+外债违约风险），IMF提供贷款——附带条件："你必须削减赤字/贬值货币/开放市场——只有你改变了导致危机的政策，我们才会借钱给你。"

这种"条件性"是IMF的力量来源——没有它，IMF只是一个无抵押贷款机构。但它也是全球反IMF情绪的根源：1997年亚洲金融危机——IMF的条件贷款要求韩国和印尼实行紧缩政策——韩国人到现在都记得"IMF"这个词——它意味着"国家主权被拿走了"。阿根廷在2001年崩溃后——从IMF借了最大的单笔贷款——然后违约——然后用了十五年摆脱IMF的"条件"。

**这个悖论的核心："你需要我——但你恨我。"没有任何借款人对IMF的贷款说"谢谢"——他们在拿到钱的那一刻就开始计算如何尽快还清然后脱离IMF的"条件"。**


## 模块三：Bretton Woods 三兄弟的对照

| | IMF | 世界银行 | WTO |
|---|---|---|---|
| 核心功能 | **危机贷款+政策条件** | 发展贷款+减贫 | 贸易规则+争端解决 |
| "产品" | **紧急援助——附带政策条件** | 长期贷款——附带政策建议 | 裁决——附带无执行力量 |
| 投票权 | 冻结在1944年 | 冻结在1944年 | 一国一票（无冻结） |
| 当前最大挑战 | **CN无条件贷款的竞争** | AIIB/NDB竞争 | **上诉机构瘫痪** |
| "谁最恨我" | **借款人——因为条件性** | 较少（贷款条件不那么苛刻） | 美国——因为它阻止了上诉机构的运作 |
| 衰退程度 | 低——金融危机仍然发生 | 中——发展需求仍在但竞争者出现 | **严重——核心功能无法运作** |

**三个Bretton Woods机构中，IMF是最不容易过时的——因为金融危机永远不会消失。** 只要国家继续有国际收支危机——IMF就有存在的理由。世界银行可以被AIIB分流——因为发展贷款有替代品。WTO可以被双边协议替代——因为贸易规则可以双边协商。但当一个国家面临全面的金融崩溃——没有人有IMF的全球债权人协调能力——这个功能只有IMF有。
