> 日期：2026-10-02 ｜ 状态：**待评审**

> 并为每一格写清：判据是什么、反例是什么、以及为什么它【不适用」。**

## 一、要解决的问题

现有诊断工具（L0–L11 + SUL）**只为国家设计**。而档案库里：

| 类型 | 数量 | 框架对它有测量构造吗 |
|---|---|---|
| 国家 | 21 | ✅ 有 |
| **企业** | **11** | **❌ 没有** |
| **国际组织** | **11** | **❌ 没有** |
| 次国家实体（台湾等） | 3 | ❌ 没有 |

**⇒ 46 个主体里 25 个（54%）在用一套为国家设计的量表。**

**现在的实际做法是「静默套用」** —— 把「主权」「全球秩序价值」这类**只对国家成立的维度**，
直接问到企业头上。**后果不是数据错，是问题本身不对题**：
得到的分数看起来是诊断，实际是**被削足适履装进国家模具里的东西**。

**这和本轮查出的其它病同型**：

* 八维值域文档称「代码真相」，而代码零命中
* L5 让用户评四项，只有一项被读
* 反馈回路标题写「闭环」，实际是静态文案

**共同的形状：形式上有，实际上不对题。**

## 二、三条设计原则

### 原则 1：判据必须可核

每个分类维度要能回答：**「凭什么把它归到这一类？」**
现在的判据只存在于 47 份档案的举例里，没有独立写出来。

### 原则 2：分类必须有反例

```
维度：锁定模式 → 交易式
  判据：用资源购买身份/关系，从未真正建构
  反例：什么情况下【不】归这一类？  ← 现在完全没有
```

> **没有反例的分类维度是不可证伪的 —— 它会把任何主体都收进去。**

### 原则 3：不适用要明说（这一条是第一价值）

**❌ 的格子不许静默套用，必须写明「为什么不对题」。**

这比新增维度更重要 —— **因为「静默套用」正是当前最大的失真来源**。
一个明确的「不适用」，比一个被硬凑出来的 1–5 分有价值得多。

## 五、详表：C 企业（最大的缺口，11/46）

**为什么先做这一格**：企业占 11/46，且它和国家的差异最大 ——
**国家的维度几乎全部要改写或判不对题**。

| 维度 | 判定 | 该类型的对应物 / 不对题的理由 |
|---|---|---|
| **L2 连续性类型** | ⚠️ 需改写 | 主体型 = **创始人/品牌驱动的身份**（如 OpenAI、SpaceX）；秩序型 = **制度驱动的身份**（如 TSMC 的代工秩序、ASML 的垄断秩序）。**「混合型」在企业里更常见**（创始人 + 制度） |
| **L3 存在方式** | ❌ **不对题** | 国家的四项（主权／文化延续／制度／象征）对企业的对应物**不是弱化，而是不存在**。企业的存在方式应另立：**① 持续盈利 ② 不可替代性 ③ 生存许可（监管/政治）** |
| **L4 建构来源** | ✅ 适用 | 创业故事=建国神话；技术积累=制度遗产；**行业标准=文化传统**；**被起诉/被制裁的经历=创伤锚点** |
| **L5 维持机制** | ⚠️ 需改写 | 合法性→**市场认可**；忠诚→**员工与客户忠诚**；仪式→**企业文化仪式**（全员会/发布会）；叙事→**品牌故事**。**注意：「忠诚」在企业里是四格里最实的一格**（国家那四格里它反而是被丢弃的三个之一） |
| **L6 秩序价值** | ❌ **不对题** | **企业不提供全球秩序**。它提供的是**产业链位置**。这一格应替换为：**供应链不可替代度 ／ 标准制定权** |
| **L7 他者系统** | ⚠️ 需改写 | 四类他者（理想/观众/敌人/镜像）**对企业的映射不同**：理想他者=标杆企业；观众他者=**监管者与资本市场**；敌人他者=竞争对手；镜像他者=**同技术路线的对手**（如台积电与三星） |
| **L8 创伤→恐惧** | ✅ 适用 | 核心恐惧应改写为企业的四种：**被替代**（技术路线被跳过）／**被断供**（上游卡脖子）／**被监管消灭**（合规性死亡）／**被地缘政治波及**（非自愿选边） |
| **L9 战略选择** | ⚠️ 需改写 | 四类手段（外交结盟/军事威慑/经济制裁/文化输出）→ 企业的：**联盟与合资／技术封锁与专利／价格与产能／生态与标准** |
| **特有维度（新增）** | — | **① 资本结构**（谁控股、受哪国管辖）**② 技术依赖**（上游单点）**③ 监管暴露**（在几个法域被管）**④ 供应链位置**（是否单点） |

**⇒ 关键结论**：企业不是「国家的缩小版」。**L3 与 L6 对它是❌，L2/L5/L7/L9 要整体改写。**
**现在把它们当成国家来问，得到的分数是伪诊断。**

## 六、详表：B 国际组织（11/46）

| 维度 | 判定 | 说明 |
|---|---|---|
| **L3 存在方式** | ⚠️ 需改写 | 主权→**成员国让渡的权限**；文化延续→**共同规范**；制度→**决策规则**（一致同意/加权）；象征→**合法性象征** |
| **L6 秩序价值** | ✅ 适用（且是它的本业） | 国际组织的存在意义**就是**秩序供给 |

## 八、"判据 + 反例"的写法（以 L2 连续性类型为例）

**这是形式化要求的样子** —— 每个维度都要写成这样，才算可用。

### L2 连续性类型

| 枚举 | 判据（凭什么归这类） | 反例（什么情况下**不**归这类） |
|---|---|---|
| **主体型** | ① 其身份叙事以「我们是谁」为核心；② 存在一个**不可让渡的自我定义**；③ 让步不等于身份自杀 | **反例**：如果它在历史上有过**彻底否定前一阶段的转向**（如日本脱亚入欧），它就不是主体型 —— 是摆荡式 |
| **秩序型** | ① 其身份叙事以「维持某种秩序」为核心；② 秩序的崩坏 = 自身的崩坏；③ 能力可以度量，身份不能 | **反例**：如果它在秩序崩坏后**仍能重建自我定义**（如战后德国），那它的核心不是秩序本身，而是**秩序定义能力** —— 这是德国档案里记的那个深层模式 |
| **混合型** | 对外渴望认同 + 对内严防失序 | **反例**：如果对外渴望与对内严防**不在同一个决策层**（如日本的「外部摆荡／内部家族秩序」），那它是**杂交结构**，不是单一混合型 |

**⇒ 这三行「反例」里，前两行来自档案里的真实分析，第三行来自 `MEMORY.md` 记的「日本=杂交主体结构」。**
**把它们写出来的意义是：分类从「标签」变成了「判据」。**

## 九、与其它部分的关系

| 关系 | 说明 |
|---|---|
| **与 S2b（新主体建档）** | 本框架是 S2b 的**分类器** —— 新主体进来，按类型套对应的维度表 |
| **与数据层** | **不替代判断，只约束判断**：数据能**证伪**一个分类（数据里它从没做过 X，却归到「以 X 为核心恐惧」类），**不能推出**一个分类（那是归纳）。规则见重构设计 §四之二 |
| **与 L5 的断线** | 本框架**先于**修 L5 —— 因为要先知道「维持机制在哪些类型上该读哪几项」，才知道 L5 该怎么接线（企业读「忠诚」，国家现在只读「合法性」） |
| **与「定性」二字** | 本框架**刻意不给分值**。现有的 1–5 评分是**为量化服务的**，而量化尝试已经失败（八维轴到数据天花板）。**定性分类 + 判据 + 反例**才是这套框架真正的产物 |

## 十、非目标

* **不做新主体建档**（用户明确：暂时不扩充主体）—— 本框架只为**能分类**，不为**能收纳**
* **不给分值** —— 见上
* **不追求穷尽** —— 先把 A／B／C 三类做实（占 43/46），D／E／F 写成占位并标明「未验证」
* **不改工具** —— 本框架是**规格**，工具改动排在 B3 之后

## 十一、验收（这份框架算不算立住了）

1. **每一格都有三态判定**（✅/⚠️/❌），**❌ 必须写理由**
2. **每个维度的每个枚举，都有判据 + 反例**（至少 L2 与 L8 两个维度做完，作为样板）
3. **能拿一个企业（如 ASML）走一遍**，产出与「把它当国家」**明显不同**的结果
4. **能拿一个国际组织（如 ASEAN）走一遍**，其「核心恐惧」算出来的是**失去相关性**，不是被消灭
5. **反例真的能拒绝**：拿日本档案套「主体型」，**反例条件必须触发**（它是摆荡式）
