# 俄罗斯经济半年崩溃

## 原始预测

> [!prediction] 
> 2022年制裁后，俄罗斯经济将在6个月内崩溃。

## 预测者/来源

西方主流智库+媒体（2022年2-3月）

## 时间

| 节点 | 日期 |
|------|------|
| 预测做出 | 2022-02 |
| 预测期限 | 2022-08 |
| 验证时间 | 2022-12 |

## 实际结果

俄罗斯经济2022年GDP下降2.1%，2023年恢复增长3.6%。卢布短暂暴跌后回升。能源收入支撑了财政。

- [ ] 正确
- [ ] 部分正确
- [x] 错误
- [ ] 无法验证

## 错误类型

| 类型 | 说明 |
|------|------|
| Identity误判 | 低估了俄罗斯秩序型Identity对经济苦难的耐受力——苏联时期更苦都过来了 |
| DEL遗漏 | 低估了能源收入（DEL-1）：欧洲仍在买俄气，中国/印度增加俄油进口 |
| 策略空间边界错误 | 假设制裁=行为改变，但制裁不改变Identity（互锁式/秩序型允许承受代价） |
| 弹性低估/高估 | 高估了制裁对行为的影响，低估了俄罗斯调整成本承受力 |
| 因果链断裂 | 制裁→经济崩溃→行为改变的链条在第一步就断了 |

## 教训

> [!lesson] 
> 制裁改变行为，不改变Identity。秩序型主体可以承受巨大经济代价而不改变战略方向。预测行为变化必须先评估Identity类型，再评估经济压力。

## ConStruct框架修正

| 修正项 | 原判断 | 修正后 |
|-------|--------|--------|
| 制裁→行为改变 | 高概率 | 低概率（取决于Identity类型） |
| 俄罗斯弹性 | 低（经济脆弱） | 高（Identity允许承受代价） |
