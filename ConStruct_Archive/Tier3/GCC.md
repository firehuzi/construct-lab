## 模块一：基础信息

| 字段 | 内容 |
|------|------|
| 主体名称 | 海湾阿拉伯国家合作委员会（GCC / Gulf Cooperation Council / مجلس التعاون الخليجي） |
| 成立时间 | 1981年 |
| 成员国 | 6国（沙特、阿联酋、卡塔尔、科威特、阿曼、巴林） |
| **构型** | **精英俱乐部**——不是整合式（没有超国家机构），不是协调平台（比ASEAN更强）——是"有钱的阿拉伯君主国的利益同盟" |
| **存在方式** | **"我们用钱解决阿拉伯世界的问题"**——GCC不收集会费，不发表决议，不协商统一立场。GCC做的是：沙特和阿联酋协调区域战略——其他四个成员国跟随——钱由最有钱的多出 |
| **核心恐惧** | **沙特-阿联酋竞争公开化——或伊朗威胁使GCC成员国安全分散**——任一发生，海湾君主国的利益同盟就可能分裂 |
| **身份一句话** | 我是阿拉伯世界唯一有实质功能的机构。我不说"阿拉伯统一"（阿盟的话术）——我做"利益协调"。沙特和阿联酋决定方向——科威特和阿曼提供外交智慧——卡塔尔在被孤立之后被迫归队——巴林是沙特的影子。 |


## 模块二：两个核心，双重张力

GCC不是"六国平等"——是**沙特和阿联酋的双头领导**+四个小兄弟跟随。

| 成员国 | 角色 | 核心利益 |
|--------|------|---------|
| **沙特** | 最大的经济体+人口+军事能力——"GCC的天然领袖" | 区域霸权+2030愿景（需要稳定的海湾环境） |
| **阿联酋** | 第二大经济体+最强的全球影响力（迪拜+主权基金）——"不想只做沙特的小弟" | 经济枢纽+区域影响（也门/非洲之角/利比亚） |
| 卡塔尔 | 在2017-2021年被沙特/阿联酋封锁——被迫归队后仍在寻找独立空间 | 天然气出口+半岛电视台+外交独立 |
| 科威特 | GCC的外交调解人——在沙特和卡塔尔之间穿梭 | 安全（被伊拉克入侵的创伤）+财政保守 |
| 阿曼 | "不在任何一边"——GCC中唯一和伊朗保持开放关系的成员国 | 中立调解人+马斯喀特的独立外交 |
| 巴林 | 沙特最亲密的盟友——沙特军队在2011救了巴林王室 | 沙特保护+逊尼派王室统治什叶派多数的不稳定 |

**沙特-阿联酋双核心的张力：** 阿联酋在也门、非洲之角、利比亚有独立的军事和商业野心——不想被沙特主导。沙特的2030愿景挤占了迪拜的"区域枢纽"叙事（沙特的NEOM vs 迪拜的Expo 2020/未来城市）。两者在GCC内部是"合作中竞争"——目前合作>竞争——但未来可能变化。


## 模块三：GCC vs 阿盟

| | 阿盟 | GCC |
|---|---|---|
| 成员 | 22国——从摩洛哥到阿曼 | **6国——只有海湾君主国** |
| 共同点 | 共同语言/文化（仅此而已） | **共同政体（君主制）+共同威胁（伊朗）+共同财富（石油/天然气）** |
| 决策 | 决议——不执行 | **行动——沙特和阿联酋决定，其他人跟随** |
| 金钱 | 无——阿盟没有预算做任何事 | **有——GCC成员国的石油财富=$3万亿主权基金** |
