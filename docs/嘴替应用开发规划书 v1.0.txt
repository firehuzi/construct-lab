嘴替应用开发规划书 v1.0
一、产品定位
一句话定义：在关键时刻，帮你把话说得干净、漂亮、不留后患的随身逻辑外挂。

核心Slogan：脑子没跟上？嘴替帮你先出招。

目标用户：20-35岁，正经历从学生→职场人→家庭支柱的身份过渡，频繁遇到“不会说、不敢说、说不好”的社交失语时刻。

产品内核：基于脑科学（抑制控制、认知灵活性、工作记忆）的场景化表达辅助工具。不是教人吵架，而是帮助用户在情绪高压下仍能精准表达。

二、核心场景：双引擎模型
🔥 引流引擎：过年嘴替
场景：春节期间集中爆发的催婚、攀比、借钱、被白嫖等家庭/社交冲突。

产品形态：一个可独立传播的H5测试互动页（“过年社交大考模拟器”），内含方言版金句，引导下载小程序。

传播钩子：“今年过年，别再被问住了。”

🏠 留存引擎：职场嘴替
场景：高频的职场即时回应（开会被cue、被甩锅、被推活、提加薪等）。

产品形态：微信小程序，提供文字/语音输入式的实时话术救场，以及场景模拟预演和事后复盘。

留存钩子：“明天开会，不能再嘴笨了。”

用户因过年嘴替而来，因职场嘴替而留，形成增长飞轮。

三、MVP功能模块（V1.0）
只保留最核心闭环，一切能用微信原生能力的就不自建。

1. 文字救场模式

用户在聊天框输入“对方说的话”，调用LLM分析，返回2-3条不同风格的回应话术（幽默化解、逻辑反击、温柔挡回）。

支持方言风格生成（东北、川渝、粤语等），通过Prompt实现。

2. 场景模拟预演

内置三个高频场景：过年催婚、职场推活、被借钱/白嫖。

AI扮演“对方”发起挑战，用户输入回应后，AI打分并给出改进建议。

3. 话术卡分享

每次生成的好用回应，可一键生成精美图片卡片，分享到朋友圈/群聊，自带小程序码，形成裂变。

4. 简单用户系统

微信一键登录，收藏话术，记录训练进度。

四、技术架构（一个人+AI精简版）
模块	选型	说明
前端	微信小程序（原生或Taro）	免审、即更、分享路径最短
后端	Python FastAPI + SQLite	FastAPI开发快，AI写代码质量高；初期SQLite足够，后续可切PostgreSQL
部署	单台云服务器ECS（2核4G） + Vercel托管H5	成本极低
大模型	DeepSeek / 通义千问 API	国内可用，成本低，响应快
语音转文字	微信原生“语音输入”能力	免费且体验好，不额外开发ASR
缓存	Redis（单机）	缓存热点话术，降低模型调用成本
存储	云OSS + CDN	存放分享卡片、静态资源
核心开发范式：AI辅助编程（Cursor/Copilot），AI生成话术库和测试数据。

六、传播与增长设计
过年H5（引流）

标题：《过年社交大考，你能撑到第几关？》

形式：选择题测试，包含催婚关、攀比关、借钱关、白嫖关。

结果生成“过年生存力报告”，附带小程序码引导深度使用。

职场场景（留存）

每次生成“神回复”后可一键生成分享卡片。

每周推送“本周职场嘴替战绩”，鼓励用户分享。

方言金句库（传播货币）

内置经典方言语录的“翻译”对照（如“你瞅啥”翻译成不同方言），易于被截图传播。

八、关键成功指标
原型验证阶段：催婚场景下，生成的回复让5个测试用户中至少4人觉得“这就是我想说的”。

MVP内测期：日活用户周留存率>30%（说明职场场景确实高频有用）。

国庆练兵后：分享卡片带来的新用户占比>20%。

春节引爆期：H5 PV达到10万+，小程序新增用户破万。
