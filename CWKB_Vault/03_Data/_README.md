# 03_Data

> ★ **本目录当前【声明为空】。** 这份 README 说明它该装什么、为什么现在空、以及填它需要什么。
> 它是 S1.4 的产物：**让「空」变成被声明的、可机器查的状态**，而不是靠人记得它还没做。

## 该装什么

数据层：**本仓自己产出的、可复算的**数据（不是外部数据源的原始副本）。

## 为什么现在空

本仓的数据现在散在 `construct-engine/data/` 下（依据档案、UCDP 提取、案例）。而 `CWKB_Vault` 是**知识库**，两者的边界没有定过。

## 填它需要什么

① 先定**边界**：什么进 `construct-engine/data/`，什么进这里。② 定完再往里放，否则会变成同一个东西两个位置（本项目已经犯过：两份同 title 的文件）。

## ⛔ 不许拿什么填

⛔ 不许把 `construct-engine/data/` 整个拷进来 —— 那会立刻造出第二份真相。

---

**审计**：`python -B construct-engine/cwkb_audit.py` 会把「声明为空」与「没人管的空」分开报。
