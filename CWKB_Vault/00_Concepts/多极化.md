# 多极化

## 定义

> [!definition] 核心定义
> 国际体系中存在三个以上具有结构性影响力的主体。不是数量概念——是权力分散化导致单一主体无法单方面定义秩序的状态。

## ConStruct映射

| 层级 | 映射 |
|------|------|
| L2 | 所有连续性类型——多极化改变所有主体的外部环境 |
| L3 | 环境解释机制——同一多极化×不同Identity=不同策略 |
| L5 | 精英对多极化的利用——摆荡式=机会，整合式=威胁 |
| L6 | 制度对多极化的适应——联盟重组、机构改革 |
| L7 | 他者结构重组——旧敌可能变伙伴，旧友可能变对手 |
| L8 | 多极化是机会还是威胁——中国=机会，美国=威胁，EU=困惑 |

## 观察指标

1. **权力集中度**：Gini系数式指标——权力是否从1极分散
2. **联盟流动性**：联盟是否从固定变为流动
3. **制度代表性**：UN/IMF/WB是否反映新权力分布
4. **规则竞争**：是否有并行规则体系（SWIFT vs CIPS）
5. **叙事多样性**：是否多种秩序叙事并存

## 典型案例

| 主体 | 对多极化的反应 | 备注 |
|------|-------------|------|
| 中国 | 推动多极化 | 秩序型——新秩序=Identity投射 |
| 俄罗斯 | 推动多极化 | 秩序型——打破单极=生存 |
| 美国 | 抵制多极化 | 交易式——单极=谈判优势 |
| 印度 | 利用多极化 | 自主局——多极=更多自主空间 |
| EU | 困惑 | 整合式——多极化=规则碎片化=Identity威胁 |

## 反例

| 主体 | 为什么不算 | 边界条件 |
