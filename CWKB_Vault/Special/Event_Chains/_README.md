# Special\Event_Chains

> ★ **本目录当前【声明为空】。** 这份 README 说明它该装什么、为什么现在空、以及填它需要什么。
> 它是 S1.4 的产物：**让「空」变成被声明的、可机器查的状态**，而不是靠人记得它还没做。

## 该装什么

事件链：**一件事如何传导到另一件事**的链式记录（A 引发 B、B 引发 C）。

## 为什么现在空

从未开始。而它是「传导分析」的载体 —— 《重构设计》里 S4 的输出之一。

## 填它需要什么

① 每条链：起点事件 ／ 中间环节 ／ 终点 ／ **每一环的出处**；② 优先从已有的四个案例里抽（海湾 1991 ／ 俄乌 2022 ／ 中印 2020 ／ 印巴 2023）。

## ⛔ 不许拿什么填

⛔ 不许把「A 导致 B」写成没有中间环节的一句话 —— 那正是因果链缺环（G6）那个病。
