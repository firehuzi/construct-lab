# 秩序

## 定义

> [!definition] 核心定义
> 国际体系中行为体共同接受的规则体系及其执行机制。秩序不是和平——是可预期的互动模式。秩序崩溃≠战争，=不可预期。

## ConStruct映射

| 层级 | 映射 |
|------|------|
| L2 | 秩序局——Identity通过维持/创造秩序来延续 |
| L3 | 秩序维护机制——规则制定+执行+惩罚 |
| L5 | 精英对秩序的利用——秩序=权力合法化的框架 |
| L6 | 制度=秩序的具体化——UN/WTO/NATO |
| L7 | 他者对秩序的接受/拒绝——承认秩序=承认他者权威 |
| L8 | 秩序是Identity的外化——美国秩序=美国Identity的世界版 |

## 观察指标

1. **规则覆盖率**：多少行为体遵守多少规则
2. **规则执行度**：违反规则的代价是否可预测
3. **规则更新能力**：秩序能否适应权力转移
4. **规则竞争度**：是否有并行规则体系

## 关键诊断

> [!warning] ConStruct核心判断
> 秩序不是中性的——每套秩序都嵌入创造者的Identity。挑战秩序≠挑战规则，=挑战创造者的Identity。这就是为什么中美竞争无法通过"规则调整"解决。
