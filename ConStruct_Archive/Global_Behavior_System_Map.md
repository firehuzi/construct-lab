## B1：场景三级网络——谁驱动谁

### 分类逻辑

按"在系统因果链中的位置"将十个场景划分为三层：

| 层级 | 定义 | 驱动方向 | 反馈能力 |
|------|------|---------|---------|
| **引擎层** | 自身动力源——不需要外部输入就能持续运转 | 向外驱动 | 不依赖外部，但接收外部信号调整参数 |
| **传导层** | 中介——接收引擎信号，转化为多个下游信号 | 上下游双向 | 强——它们的输出改变引擎和其他表现层的参数 |
| **表现层** | 终端——引擎和传导的张力在此显现 | 主要被驱动 | 弱——但特定节点（台海）有反向触发引擎的能力 |

### 各层内部张力

| 层级 | 核心张力 | 稳定性 |
|------|---------|--------|
| **引擎层** | 技术竞争（场景9）vs 财政约束（场景10）——AI需要无限投资，金融有有限空间 | 中高——两台发动机互相调节 |
| **传导层** | 资源供给 vs 地缘需求——四个传导节点的价格信号通过全球市场同时影响引擎和表现 | 中——任何一个节点中断都有全系统后果 |
| **表现层** | 大国竞争的表象——四个投射区是引擎张力的终端表达 | 中低——被两个上层驱动，自主性弱 |

### 关键反馈回路

```
反馈①：台海→引擎（正反馈，唯一）
  台海紧张 → TSMC停产风险 → 芯片供断 → AI引擎停摆 → 金融冲击
  → US财政+军事选项收缩 → CN在台海/南海获得更大空间 → 台海进一步紧张

反馈②：中东→金融（正反馈）
  中东油价↑ → 全球通胀 → 各国财政空间收缩 → US/CN/IN军事/外交选项都受限
  → 全球投射能力下降 → 各种表现层的冲突风险变化

反馈③：金融→所有（调节性反馈）
  美债利息↑ → US财政空间↓ → 全球投射能力↓
  → 表现层中US角色收缩 → CN空间相对扩大 → 动力分布的再平衡
```

### 系统动力学特征

| 特征 | 描述 | 含义 |
|------|------|------|
| **双引擎** | AI/芯片 + 金融——两个自驱动力源 | 任何一个引擎熄火都会波及全系统 |
| **四传导** | 中东(油)+非洲(矿)+俄乌(粮)+北极(航道) | 传导层是系统的价格信号管道 |
| **一反馈** | 台海——唯一能从表现层反向炸掉引擎层的节点 | 台海不是"另一个冲突"——是系统的致命弱点 |
| **金融管道** | 金融不是独立场景——是所有场景的底层基础设施 | 任何场景的紧张都会通过金融管道传导 |

### ICC在系统动力学中的位置

ICC影响的是**传导速度**：
- 低ICC主体（RU）——在传导层中行为更激进，传导更快
- 中ICC主体（IN/CN）——传导渐进但持续
- 互锁式主体（IL-IR）——传导不受ICC约束，对抗自我维持

ICC影响的是**表现层的稳定性**：
- 高D3主体（CN D3=高，内部一致）——表现层行为可预测
- 低D3主体（PH D3=极低，家族战争）——表现层行为不可预测

### 系统最脆弱节点排序

| 排序 | 节点 | 脆弱原因 | 爆炸半径 |
|------|------|---------|---------|
| **1** | 台海 | 唯一能从表现层反向炸掉引擎层的节点 | 全系统 |
| **2** | 中东（霍尔木兹） | 能源价格→全球通胀→所有策略空间同时收窄 | 全系统（速度比台海慢） |
| **3** | 美债利息 | 金融引擎熄火→US全球投射↓→所有表现层重新洗牌 | 全系统（渐进） |
| **4** | 非洲矿链 | 芯片/电池原料端中断→AI引擎减速 | 引擎层→全系统 |
