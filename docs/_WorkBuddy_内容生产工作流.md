**排版规范**: 暖白底+紫标(#533483)+珊瑚红(#E94560)，用 `<section>` 标签（不用 `<div>`，微信丢弃 div 样式），内联 style

**数据流**: Markdown档案 → JSON桥接 → 诊断工具/内容生产（公众号+框架共用数据层）

**分发平台**: 
1. 公众号（首发，中文全文，视觉化排版）
2. Substack（英文版，24-48 小时后发，用 blockquote/table 等原生标签）
3. Substack Notes → Reddit r/geopolitics + r/singapore → Facebook群组（冷启动引流）

**内容策略**: 长篇幅+结构性分析，"冻结局"(frozen settlement)框架为标志性分析模型
**系列署名**: ConStruct Lab — Structural diagnosis. Not structural talk.
**翻译**: 中文先构思，AI 翻译英文
