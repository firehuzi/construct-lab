# ConStruct Lab 内容输出形态 v1.0

> 基于三层数据底座（COW 骨架 + UCDP 肌肉 + GDELT 脉冲）的九种内容形态，覆盖从"日常跟踪"到"深度认知"的全光谱。
> 
> 所有输出共享同一个**结构驱动的分析引擎**，遵循四条反洗脑原则：数据锚定、结构驱动、叙事识别、不确定性标注。

---

## 总览

```
数据卡片（极简）
    ↓
事件快评（日常）
    ↓
构型迁移预警（自动化）
    ↓
地缘政治时序报告（周期性）
    ↓
构型对比（深度）
    ↓
国别结构诊断（年度锚点）
    ↓
情景推演（高级）
    ↓
叙事考古（长期差异化）

结构词典（独立工具）
```

## P0 — 国别结构诊断报告

**形态**：长文本（3000-5000 字），结构化章节

**结构**：
1. 数据摘要表（指标/数值/来源/含义）
2. 近期 GDELT 信号切入
3. 深层结构解释（Identity → Method → Fear）
4. 历史骨架约束（COW + UCDP）
5. 结构性判断——三情景路径（A最可能 / B次可能 / C极端）
6. 内部政治约束段
7. 叙事识别

**使用场景**：年度/季度的主体深度分析，ConStruct 知识库的锚点

**已有覆盖**：Tier1 8国（CHN/USA/RUS/JPN/IND/IRN/ISR/EU）

**产出周期**：季度更新，异常驱动重跑

---

## P0 — 事件快评

**形态**：短文本（500-1500 字），针对单一事件

**框架**：
1. 事件事实（1-2 句）
2. 结构锚定（3-5 句）：触动了哪国的哪个身份/方法/恐惧
3. 历史参照（2-3 句）：COW/UCDP 有无类似先例
4. 走向判断（1-2 句）
5. 反洗脑提示（1 句）：别被哪种常见叙事忽悠

**使用场景**：GDELT 每日热点事件自动生成，公众号/Substack 日常运营

**自动化**：GDELT 异常事件触发 → deepseek 生成 → 推送审计队列

---

## P1 — 地缘政治时序报告

**形态**：以时间线为核心维度的汇总报告

**框架**：
1. 本期概览（1 段）：周期内全球冲突格局核心变化
2. 热点事件时序图：GDELT 事件密度/情绪曲线 + 关键节点标注
3. 国别状态更新（每国 2-3 句）：对比上一期行为模式变化
4. 结构性趋势（3-5 点）：哪些身份/方法正在加速演变
5. 反洗脑预警：被媒体放大但结构上不重要 vs 被媒体忽视但结构上重要的

**使用场景**：月度/季度汇总，"个人知识库索引"

**已有基础**：世界地图已展示 UCDP 年度时序变化，扩展至每周/每月即可

## P1 — 数据卡片

**形态**：单一主体/主题的核心数据摘要，图表为主、文字为辅

**内容**：
- 3-5 张图表（情绪趋势、事件密度、冲突周期、领土变更时间线）
- 1-2 句结论
- 数据来源标注

**使用场景**：社交媒体传播，作为其他报告的"预告片"或"摘要"

**自动化**：从 PG 数据直接生成 HTML/CSS 卡片模板

---

## P2 — 情景推演报告

**形态**：针对"如果 X 发生，Y 会如何反应"的结构性推演

**框架**：
1. 假设条件（1-2 句）：X 事件发生
2. 受影响的行为体（列出）：哪些主体的身份/方法/恐惧会被触发
3. 推演路径（2-3 条）：每条路径的结构性驱动因素
4. 最可能路径：基于历史骨架和当前方法阶段的判断
5. 不可逆点（1-2 条）：如果什么发生，结构会不可逆地改变

**使用场景**：高概率高影响情景预演（台湾、朝鲜、南海、美国大选后同盟政策）

**投入**：高——需人工推演 + 多轮 AI 生成

## P2 — 构型对比

**形态**：两个同构型国家为什么走相反方向

**框架**：
- 相同构型 + 共同约束 → 不同的行为输出
- 差异锚点：各自的 L4 建构来源、L8 创伤系统、L7 他者配置
- 结构性结论：构型相同但约束集合不同 → 行为差异的可解释性

**示例**：日本 vs 韩国 —— 同为"冻结局"，对华行为完全不同

**为什么只有 ConStruct 能做**：别人只能做国别对比，你做的是**结构对比**——对比的不是国家，是约束集合。

---

## P2 — 叙事考古

**形态**：挑一条流行叙事，用 COW 200 年数据逐条检验其真假

**框架**：
1. 提出叙事（如"修昔底德陷阱"）
2. 数据检验：COW 战争记录中，霸权国与挑战者之间的战争模式是否符合该叙事
3. 结构替代解释：有没有更好的结构变量解释这些战争
4. 结论：叙事几分真、几分假、为什么流行

**为什么只有 ConStruct 能做**：数据底座是 200 年战争 + 1989 年 UCDP——你有**长期证据**，别人只有**短期情绪**。

---

## P2 — 构型迁移预警

**形态**：实时追踪某个主体什么时候从一种构型跨到另一种

**框架**：
- 信号：GDELT 行为模式与当前构型预测出现系统性偏差
- 阈值：连续 N 天 ≥3 条 verification_item 被反证
- 输出：`feedback_rules.json` 中 `confidence_delta` 触底 → 推 review_queue → 人工复核
- 判断：此主体正在从"冻结局"向"正常国家化"迁移，还是只是短期波动

**已有基础**：`detect_structure_contradictions.py` + `feedback_rules.json` 53 主体 114 验证项已就位

## P0 — 结构词典

**形态**：独立条目，每个概念一篇短文。ConStruct 核心差异化资产——不是内容，是工具。

**条目模板**：
```markdown
# [概念名] ([英文])

> 一句话定义。

**所属层**: [11层框架中的位置，如 L2/L6/L8]
**适用构型**: [哪些构型用到这个概念]
**运作机制**: [核心机制 1-3 条]
**典型主体**: [国家名]: [表现]
**常见误解**: ❌ "[误解]" — 实际情况: [纠正]
**相关条目**: [交叉引用]
```

**首批 10 条目**: 冻结局(Frozen Settlement)、天下体系型Identity、打而不占、交易式方法⑤、互锁式(Interlocked)、ICC内部耦合度、SUL战略不确定性层、秩序建立能力、方法七→方法八过渡、民族/族群/文明型Identity区分

**机制**: 每篇国别诊断/事件快评末尾自动标注"本文引用的结构词典条目: [...]"，条目页面交叉引用形成知识网络

**产出**: `content/lexicon/` 下 Markdown 文件 + 概念索引页面

**使用场景**: 防AI洗脑的疫苗——读者不需要从头学ConStruct框架，遇到陌生概念点进去就能看懂。长远看，概念被外部引用=话语权建立。

## 核心原则：反洗脑四标准

无论哪种形态，每份输出必须满足：

| 原则 | 说明 | 检查标准 |
|---|---|---|
| **① 数据锚定** | 每个判断都能追溯到 GDELT/COW/UCDP 数据 | 阅读者能看到"这来自哪条数据" |
| **② 结构驱动** | 结论从 Identity → Method → Fear 框架推导 | 能看到"身份 → 方法 → 行为"的逻辑链 |
| **③ 叙事识别** | 主动识别并解构常见洗脑叙事 | 每份报告有"别被哪种叙事忽悠" |
| **④ 不确定性标注** | 区分高/中/低置信度判断 | 标注 [高/中/低，依据: …] |
