# 缓冲区

## 定义

> [!definition] 核心定义
> 两个竞争性主体之间的地理/政治空间，其存在降低直接冲突概率。缓冲区不是权力真空——它是权力梯度的缓冲地带。

## ConStruct映射

| 层级 | 映射 |
|------|------|
| L2 | 秩序局——缓冲区是秩序的地理化 |
| L3 | 空间隔离机制——距离=安全 |
| L5 | 精英对缓冲区控制的竞争 |
| L6 | 缓冲区的制度化（中立化条约、非军事区） |
| L7 | 缓冲区=他者之间的否定性空间——谁控制它=谁定义边界 |
| L8 | 缓冲区是Identity的延伸——失去缓冲区=Identity暴露 |

## 观察指标

1. **缓冲区宽度**：地理纵深有多大
2. **缓冲区控制度**：谁实际控制
3. **缓冲区稳定性**：是否被蚕食/打破
4. **替代方案**：技术/威慑能否替代地理缓冲

## 典型案例

| 主体 | 表现 | 备注 |
|------|------|------|
| 俄罗斯 | 乌克兰=最后缓冲区 | 失去=Identity暴露（莫斯科平原无天险） |
| 中国 | 朝鲜=东北缓冲 | 维持现状>统一（统一=美军到鸭绿江） |
| 以色列 | 戈兰高地/黎巴嫩南部 | 小国无缓冲=存在性脆弱 |
| 伊朗 | 叙利亚/伊拉克=战略纵深 | 互锁式需要纵深=代理人网络 |

## 反例

| 主体 | 为什么不算 | 边界条件 |
|------|-----------|---------|
| 美国 | 两大洋=天然缓冲 | 不需要人为缓冲区——地理已经解决 |
| 英国 | 英吉利海峡=天然缓冲 | 海洋缓冲vs陆地缓冲——不同的安全逻辑 |
| 新加坡 | 无缓冲区=冻结局条件 | 零纵深=必须靠否定自身维持安全感 |
