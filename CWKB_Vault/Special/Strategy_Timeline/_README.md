# Special\Strategy_Timeline

> ★ **本目录当前【声明为空】。** 这份 README 说明它该装什么、为什么现在空、以及填它需要什么。
> 它是 S1.4 的产物：**让「空」变成被声明的、可机器查的状态**，而不是靠人记得它还没做。

## 该装什么

策略时间线：**主体在时间轴上的策略选择**（它何时选了哪条路径、放弃了哪条）。

## 为什么现在空

从未开始。而它是「路径空间」的**事后对照物** —— 写下的路径与实际走过的那条，要能在同一根时间轴上比。

## 填它需要什么

① 每个主体一条时间线；② 每个点标**当时的可选集**（不是事后看只有一条）；③ 与 `data/cases/filled/` 的路径空间对账。

## ⛔ 不许拿什么填

⛔ 不许画成「它做了 X」的单线 —— 单线会抹掉「当时还有别的可能」，而那正是本框架唯一能提供的东西。

---

**审计**：`python -B construct-engine/cwkb_audit.py` 会把「声明为空」与「没人管的空」分开报。
