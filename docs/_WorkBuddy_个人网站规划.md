## 一、项目定位

**一句话**：把分散在公众号、Substack、产品页面的内容统一聚合到一个中央枢纽，既是个人品牌官网，也是作品展示窗口，也是独立发布平台。

### 三个角色

| 角色 | 说明 |
|------|------|
| **内容中枢** | 公众号文章 + Substack 文章 + 独家内容，统一入口 |
| **作品集** | 双镜实验产品、四层原型体系、开发项目展示 |
| **品牌门面** | ConStruct Lab 方法论展示、个人简介、联系方式 |

### 目标受众

- **中文读者** — 地缘推演台公众号受众，对地缘政治结构性分析感兴趣
- **国际读者** — Construct Lab Substack 受众，需要英文入口
- **潜在合作方** — 产品、内容、学术合作方通过网站了解你的全貌

## 三、各页面详细内容

### 1. Home 首页

**目标**：3 秒内让访客知道"这是谁、做什么、值得继续看"。

**内容模块**：
- **Hero 区** — 名字 + 一句话定位（"在代码和心理学之间，做地缘结构诊断"）
- **最新内容** — 最近 3 篇文章卡片（中英混合，按时间排序）
- **核心项目** — 双镜实验 + Construct Lab + 骰评系列 卡片
- **方法论入口** — ConStruct Lab 简介卡片，链接到 About 页
- **CTA** — 订阅 / 关注 / 联系

### 2. About 关于

**目标**：建立信任和认知深度，展示底层逻辑。

**内容模块**：
- **个人简介** — 胡子是谁，做什么，为什么做

## 四、技术方案

### 技术栈

| 层 | 选择 | 理由 |
|----|------|------|
| **框架** | Astro | 内容型静态站最佳选择，SEO 好、速度快、支持 MDX |
| **样式** | Tailwind CSS | 原子化 CSS，开发效率高，与 baoyu-design 兼容 |
| **内容管理** | Astro Content Collections | Markdown 文件管理文章，Git 版本控制 |
| **国际化** | Astro i18n | 原生路由级双语支持 |
| **字体** | 系统字体 + 可选 Google Fonts | 中英文混排优化 |
| **图标** | Lucide / Heroicons | 轻量 SVG 图标 |
| **部署** | CloudStudio（免费起步）→ Vercel（备选） | 免费域名 + 一键部署 |

### 设计方向

- **审美**：哲学+技术融合，克制但有辨识度
- **色调**：浅色为主（符合你的公众号排版偏好），深色模式可选
- **排版**：长文优先，阅读体验为核心
- **动效**：克制，只在交互反馈和内容揭示上使用
- **字体策略**：
  - 中文：思源黑体 / 系统字体
  - 英文：Inter / 系统字体
  - 标题：可考虑衬线字体增加质感

### 用 baoyu-design 出设计稿
