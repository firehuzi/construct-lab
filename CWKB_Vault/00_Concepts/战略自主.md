# 战略自主

## 定义

> [!definition] 核心定义
> 主体在关键决策上不依赖外部强权的能力和意愿。不是绝对独立，而是关键路径上的自主选择权。

## ConStruct映射

| 层级 | 映射 |
|------|------|
| L2 | 自主局——主体通过自主决策维持连续性 |
| L3 | 自主决策机制——不依赖外部授权的决策流程 |
| L5 | 精英是否受外部约束——自主精英vs依附精英 |
| L6 | 制度是否允许独立行动——主权制度vs联盟约束 |
| L7 | 他者是否被承认为权威来源——自主vs依附 |
| L8 | 自主是本体论必然还是工具性选择——法国vs日本 |

## 观察指标

1. **军事自主**：能否独立发动/终止军事行动
2. **能源自主**：能源进口依赖度是否超过临界线
3. **金融自主**：货币主权、支付系统独立性
4. **技术自主**：关键技术链的自主可控度
5. **叙事自主**：能否独立定义自身行为的意义

## 典型案例

| 主体 | 表现 | 备注 |
|------|------|------|
| 法国 | 核武独立+退出北约军事一体化（1966） | L8自主=本体论必然 |
| 印度 | 不结盟+战略自主 | L2自主局+L3多元平衡 |
| 日本 | 安全依赖美国+经济自主增强 | 自主是手段不是目的→冻结的依附 |

## 反例

| 主体 | 为什么不算 | 边界条件 |
|------|-----------|---------|
| 德国 | 军事完全依赖北约/美国 | 经济自主≠战略自主 |
| 韩国 | 安全依赖美国驻军 | 自主只在非安全领域 |
| 日本 | 安全依附是Identity结构 | 加息≠战略自主，是冻结局微调 |
