# Indexes

> ★ **本目录当前【声明为空】。** 这份 README 说明它该装什么、为什么现在空、以及填它需要什么。
> 它是 S1.4 的产物：**让「空」变成被声明的、可机器查的状态**，而不是靠人记得它还没做。

## 该装什么

索引层：**连接知识层与引擎的枢纽** —— 主体 ／ 概念 ／ 事件 ／ 判据之间的可查映射。

## 为什么现在空

**它是设计里最要紧的一个，而它是空的。** 上一条同样的病：规划写了，目录建了，内容没有。

## 填它需要什么

★ **它需要另一次设计**（本脚本不假装能填它）。要定的至少三样：① 索引什么（主体→档案？概念→判据？事件→主体？）；② 正排还是倒排；③ 引擎怎么查它（现在是脚本直读文件，没有索引这一层）。**在定下来之前，任何往里写的东西都会变成要重做的。**

## ⛔ 不许拿什么填

⛔ 不许先建一个「先用着」的临时索引 —— 索引结构一旦被引擎依赖，改它就是改指纹。
