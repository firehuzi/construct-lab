# ConStruct Lab · 主体档案 #033

### 非洲联盟（African Union / AU）

> Tier 3 · 国际组织 · 协调平台（有限整合式）——拥有整合式的机构设计，但主权优先使执行能力远低于欧盟
> 版本：v1.0 | 建档：2026-06-21 | 方向：→


## 模块一：基础信息

| 字段 | 内容 |
|------|------|
| 主体名称 | 非洲联盟（African Union / AU） |
| 成立时间 | 2002年7月9日（取代非洲统一组织，1963） |
| 成员国 | 55国 |
| 连续性类型 | **协调平台**——不是"超国家主体"，而是"成员国主权不可侵犯的协调平台" |
| 深层Identity | **"非洲共同声音"**——一个大陆、一个声音、一个命运 |
| 构型 | **协调平台（有限整合式）**——整合式的机构框架（委员会、议会、法院），但成员国主权意识远强于EU，使"整合"停留在协调层面非执行层面 |
| 存在方式 | "维持非洲共同立场"=维持自己——一旦成员国利益分歧公开化，"共同声音"失效 |
| 核心恐惧 | **被成员国抛弃**——如果非盟无法提供价值，成员国绕开非盟直接与域外大国交易 |

## 模块二：身份定位

### EU vs AU 对照

| | EU | AU |
|---|---|---|
| 主权让渡 | 部分让渡 | 坚持不可侵犯 |
| 决策 | 多数/共识 | **共识**（55国一致或接近一致） |
| 执行 | 有强制力 | 几乎无——依赖自愿 |
| 动力 | 经济依存+制度惯性 | 泛非主义理想+外部压力 |
| 预算 | ~1.7万亿€ | ~4-6亿$（差三个数量级） |

### 维持机制

| 柱子 | 功能 | 压力 |
|------|------|------|
| 和平与安全理事会 | 非洲安全 | 严重依赖外部资金 |
| AfCFTA（自由贸易区） | 内部贸易 | 进展缓慢 |
| "非洲共同立场"叙事 | 国际代表 | 利益冲突时失效 |

### 秩序价值：非洲解决方案——非洲问题非洲解决——但实践中严重依赖外部资金。

### 他者系统

| 他者 | 类型 |
|------|------|
| CN | 经济伙伴——最大贸易伙伴+基建 |
| US | 安全伙伴——影响力下降 |
| EU | 历史联系+发展伙伴——"家长式"不满 |
| RU | 军事存在——瓦格纳/非洲军团 |

### 在场景8（非洲资源竞争）中的角色

- **能做：** 发表"非洲共同立场"声明、提供谈判协调平台、推动区域一体化
- **不能做：** 强迫成员执行统一资源政策、代表成员签署协议、当成员利益冲突时充当仲裁者
