## ConStruct Lab · 全球地缘政治知识库建设方案

> 版本：v1.0 | 日期：2026-06-19 | 基于：ConStruct v2.0框架 + 全球主体档案库

---

## 一、知识库的战略定位

知识库是ConStruct Engine的**底层燃料系统**。它的功能不是替代分析，而是确保每次分析启动时，**理论依据、历史数据、事件记录、政策文本可以在一处调取**，而不是每次重新搜集。

**核心原则：**

- **一次采集，反复使用**——同一份数据不重复搜集
- **按ConStruct层级索引**——每个资源标注它服务于DEL-1/DEL-2/DEL-3或身份定位
- **人机双轨**——人可读（Markdown），机器可查（结构化索引）

## 二、知识库的六层结构

```
┌─────────────────────────────────────────────────────┐
│  Layer 1: 理论基础（"用什么框架看世界"）            │
│  经典理论著作 + 当代学术前沿                         │
├─────────────────────────────────────────────────────┤
│  Layer 2: 历史文献（"世界如何走到今天"）            │
│  外交档案 + 战略文献 + 解密文件                      │
├─────────────────────────────────────────────────────┤
│  Layer 3: 数据与事件（"世界正在发生什么"）           │
│  结构性数据 + 事件数据库                            │
├─────────────────────────────────────────────────────┤
│  Layer 4: 智库与政策研究（"世界如何被解读"）         │
│  全球智库报告 + 政策分析                            │
├─────────────────────────────────────────────────────┤
│  Layer 5: 学术资源（"学术共同体在讨论什么"）         │
│  开放获取期刊 + 学术网络                            │
├─────────────────────────────────────────────────────┤
│  Layer 6: 主体档案（ConStruct专属）                  │
│  已建档主体的身份定位 + 策略空间 + 事件链            │
└─────────────────────────────────────────────────────┘
```

### Layer 3：数据与事件（DEL-1/DEL-2/DEL-3）

#### DEL-1：基础条件（年级更新）

| 数据 | 来源 | 获取方式 | 更新周期 |
|------|------|----------|----------|
| GDP / 人口 / 贸易 | 世界银行（World Bank API） | 免费API | 年度 |
| 军费 / 武器转让 | SIPRI | 免费下载 | 年度（每年4月更新） |
| 经济展望 / 债务 | IMF WEO | 免费下载 | 半年度（4月/10月） |
| 外汇储备 / 美元占比 | IMF COFER | 免费下载 | 季度 |
| 全球治理指标 | 世界银行 | 免费下载 | 年度 |

**SIPRI军费数据库** 是DEL-1中最直接可用的资源，提供了全球各国的军费开支、武器转让数据，可直接用于主体的“军事能力”诊断。

#### DEL-2：策略变量（月级更新）

| 数据 | 来源 | 获取方式 |
|------|------|----------|
| 油价 / 能源 | EIA | 免费API |
| 利率 / 汇率 | BIS | 免费API |
| 制裁动态 | OFAC / EU制裁清单 | RSS订阅 |
| 选举日程 | 各国选举委员会 | 手动标注 |

#### DEL-3：事件脉冲（日级更新）

| 资源 | 内容 | 规模 | 获取方式 |
|------|------|------|----------|
| **GDELT（全球事件、语言与语调数据库）** | 全球新闻事件实时编码，覆盖1979年至今 | 超2.5亿条记录 | 100%免费开源 |
| **ACLED（武装冲突地点与事件数据）** | 全球240+国家/地区的政治暴力与抗议事件 | 实时更新 | 免费注册myACLED账户 |
| **UCDP（乌普萨拉冲突数据项目）** | 组织暴力的全球标准数据集，1946年至今 | 冲突年数据集+地理参考事件数据集 | 100%免费，CC BY 4.0 |
| **通用时序知识图谱数据集** | ICEWS+GDELT整合，1979-2024年，15分钟级精度 | 超40亿条事件记录 | 国家基础学科公共科学数据中心免费下载 |

**三个事件数据库的定位：**

| 数据库 | 优势 | 适用场景 |
|--------|------|----------|
| GDELT | 规模最大、覆盖最广 | 宏观趋势识别、跨区域比较 |
| ACLED | 冲突事件精细化、近实时 | 具体冲突分析、月度报告 |
| UCDP | 学术标准最高、定义最严格 | 严谨的冲突统计、跨年度比较 |

**建议：** 以ACLED作为日常事件追踪的主要来源，GDELT用于宏观趋势分析，UCDP用于严谨的冲突统计和跨年度比较。

### Layer 6：主体档案（ConStruct专属）

这是知识库的**核心资产**——已建档主体的身份定位、策略空间、事件链和条件性判断。详见《全球主体档案库建设方案》。

**当前已完成/进行中的主体：**

| Tier | 主体 | 状态 |
|------|------|------|
| Tier 1 | 美国、中国、日本、欧盟、俄罗斯、伊朗、以色列、印度 | 部分完成 |
| Tier 2 | 新加坡、塞尔维亚、英国、德国、法国、土耳其、沙特、韩国 | 待建档 |

**档案结构：** 每个主体六个模块——基础信息、身份定位（L2-L8）、策略空间（当前状态）、响应弹性、关键事件链、更新时间。

## 四、知识库管理方案

### 4.1 存储结构

```
construct-knowledge-base/
├── Layer1_Theory/
│   ├── Classics/          -- 经典理论（微信读书同步）
│   └── Contemporary/      -- 当代学术
├── Layer2_History/
│   ├── FRUS/              -- 美国对外关系文件
│   ├── NSArchive/         -- 国家安全档案馆
│   └── NSDDD/             -- 国家安全战略文件
├── Layer3_Data/
│   ├── DEL1_Structural/   -- 世界银行/SIPRI/IMF
│   ├── DEL2_Strategic/    -- 油价/利率/制裁
│   └── DEL3_Events/       -- ACLD/GDELT/UCDP
├── Layer4_ThinkTanks/
│   ├── Carnegie/
│   ├── Brookings/
│   ├── RAND/
│   └── China/             -- 国内智库
├── Layer5_Academic/
│   ├── HDiplo/
│   ├── IREON/
│   └── Journals/
└── Layer6_Archives/
    ├── Tier1/
    ├── Tier2/
    └── Index.md
```

### 4.2 索引机制

在每个Layer目录下维护一个 `INDEX.md`，标注：
- 资源名称和URL
- 更新周期
- 对应的ConStruct层级（DEL-1/DEL-2/DEL-3/L2/L4等）
- 最后更新时间
- 下次更新提醒

### 4.3 采集频率

| 层级 | 频率 | 方式 |
|------|------|------|
| Layer 1-2 | 一次性采集，按需补充 | 手动 |
| Layer 3 DEL-1 | 年度 | API自动 + 手动检查 |
| Layer 3 DEL-2 | 月度 | API自动 |
| Layer 3 DEL-3 | 日常 | RSS + 手动标注 |
| Layer 4-5 | 按需 | 手动 |
| Layer 6 | 事件驱动 + 季度扫描 | 手动 + CLI工具 |
