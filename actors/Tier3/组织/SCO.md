## 模块一：基础信息

| 字段 | 内容 |
|------|------|
| 主体名称 | 上海合作组织（SCO / Shanghai Cooperation Organisation / Шанхайская организация сотрудничества） |
| 成立时间 | 2001年6月15日（前身：上海五国，1996年） |
| 成员国 | 10国（中国、俄罗斯、印度、巴基斯坦、伊朗、哈萨克斯坦、吉尔吉斯斯坦、塔吉克斯坦、乌兹别克斯坦、白俄罗斯（2024年加入）） |
| **连续性类型** | **多元平台型**——成员的唯一共同点是"我们不是西方的安全框架的成员" |
| **构型** | **多元平台（双核）**——CN和RU是双核心——但两个核心的目标不同。CN想用SCO做经济整合（一带一路走出去的框架）。RU想用SCO做安全协调（在西方推回后，证明"我们还有朋友"）。两个核心目标不重合——SCO就是两者的最低公分母 |
| **存在方式** | **"每一次扩员=证明'多极世界'存在"**——就像BRICS通过扩员证明"全球南方存在"，SCO通过扩员证明"有一个非西方的安全框架存在" |
| **核心恐惧** | **IN-PK的内部对抗公开化（在SCO峰会期间爆发冲突）——或CN-RU对SCO方向的分歧公开化**——任一发生，SCO的"团结"叙事就破裂了 |
| **身份一句话** | 我是"不是北约的那一边"的制度化表达。中俄是双引擎——但他们的方向不完全一致。印度和巴基斯坦在同一个房间里——但他们互不交谈。伊朗加入了——因为它的其他朋友不多。 |


## 模块二：SCO的悖论——双核心的两种不同愿景

| | 中国想要SCO做什么 | 俄罗斯想要SCO做什么 |
|---|---|---|
| 核心诉求 | **经济走廊**——中亚是一带一路的关键路线，SCO提供了多边框架来保护CN的投资 | **地缘合法性**——在西方制裁后（2014/2022），SCO=证明"我们不是孤立的" |
| 对中亚 | 基础设施+能源+贸易——经济整合 | 安全主导——保留俄罗斯的传统影响力 |
| 对扩员 | 支持——更多成员=更大平台 | 谨慎——扩员稀释了RU的核心地位 |
| 对IN-PK | 想要稳定（IN-PK边境不稳=CN的CPEC项目受影响） | 不太关心——只要不影响RU-CN协调 |

**两个核心的不同目标是SCO的运作原理——不是缺点：** SCO不需要像NATO一样有"统一指挥"。它需要一个最低公分母——中亚的安全稳定+反恐合作——这是两个核心都能同意的。任何超出这个范围的——经济深度整合（CN想要）或地缘反美阵营（RU想要）——另一核心不会配合。


## 模块三：SCO vs NATO vs BRICS

| | NATO | SCO | BRICS |
|---|---|---|---|
| 核心逻辑 | 军事同盟——统一指挥 | **安全协调——双核驱动** | 信号——"我们存在" |
| 统一行动能力 | 有——第五条 | **低——无军事协调机制** | **无——无任何决策机制** |
| 成员共同点 | 民主+美国保护 | **"我们不是北约"——但内部利益各异** | **"我们不是西方"——仅此而已** |
| 最大张力 | 美国撤出 | **CN-RU方向分歧/IN-PK对抗** | **IN-CN边境对抗/沙伊竞争** |
