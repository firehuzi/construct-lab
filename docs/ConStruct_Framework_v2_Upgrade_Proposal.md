## 〇、为什么需要修订

### 技术层面

初版方案的核心公式是：

```
身份约束 × 能力约束 × 环境约束 = 策略空间
```

这是一个**乘法模型**——三个因子并列，各自独立，乘在一起得出结果。

但经过讨论，发现乘法模型有三个根本问题：

1. **Capability不是独立因子**——日本工业能力远大于以色列，但战后身份冻结了它；以色列资源远少于日本，但生存身份释放了它。能力不是"乘上去的"，是身份对资源的**解释结果**。
2. **Environment不直接进入策略空间**——同样的人口老龄化，德国看到移民，日本看到自动化，中国看到产业升级。环境相同，身份不同，策略空间不同。环境必须**先被身份解释**才能成为约束。
3. **策略空间到行动之间还有一个黑箱**——日本策略空间里有{依附美国, 战略自主, 亚洲化, 多元平衡}，但选了"依附美国"。为什么选B不选C？Strategy Selection这个环节完全缺失。

因此核心结构需要从**乘法模型**改为**因果链模型**。

### 范式层面

v1.x → v2.0 不仅是技术升级，是**范式转换**：

| | v1.x（静态分类框架） | v2.0（动态决策框架） |
|---|---|---|
| 核心问题 | 发生了什么？怎么归类？ | 这个主体认为自己是谁？因此它认为自己有哪些路可以走？ |
| 输出类型 | 描述——"日本加息、欧盟加息、美国不动" | 诊断——"三方并非对同一问题给出不同答案，他们在不同Identity约束下，面对不同DEL现实，从不同Strategy Space中选择了各自成本最低的路径" |
| 框架功能 | 分类学——把事件塞进格子（L3金融层、L4国家层、L6阵营层） | 定位工具——在因果链中定位行为的结构性意义 |
| 解释力 | 弱——格子塞满了，描述很完整，但"为什么"回答不了 | 强——每个行为的结构性意义都被因果链解释 |

**两个转向：**

1. **从分类到定位**——不再把事件塞进格子，而是在因果链中定位行为的结构性意义。"欧盟加息不是金融层事件，是区域秩序体在策略空间收缩时的防守动作"
2. **从描述到决策**——不再输出"发生了什么"，而是输出"为什么逻辑上只能这样"

**事件的escalation链条：**

```
金融行为 → 战略行为 → 文明行为
```

利率只是最外层的表现。真正发生变化的，是不同文明体对未来秩序变化的预期分化。欧盟预期秩序碎片化所以防守，日本预期策略空间需要扩张所以主动调整，美国预期自己仍能维持选择权所以不动。这三个预期不是"观点不同"，是Identity对同一环境的不同解释产生的三个不同的策略空间边界。

## 一、诊断：v1.2的强项与短板

### 强项（不需要改的）

| 能力 | 已覆盖层 | 例子 |
|------|----------|------|
| 诊断"主体是谁" | L1 + L2 + L3 | 特朗普=主体型/交易式；中国=秩序型/整合式 |
| 诊断"主体为什么这样做" | L4 + L8 + L7 | 2018退出=否定奥巴马的身份建构动作 |
| 诊断"主体不能做什么" | L5 + L6 + L10 | 冻结局不能松，互锁式不能软 |
| 诊断"行为约束的结构性来源" | L2↔L10 + 三条反馈回路 | 2018退出锁死2026协议上限 |

### 短板（必须补的）

| 缺失 | 症状 | 根源 |
|------|------|------|
| **环境→身份解释→策略空间** | 能说"特朗普必须签"，但不能说"油价跌到$90后，他的叙事窗口打开还是关闭" | 环境是客观存在，但主体不直接面对环境，主体面对的是"自己认为能做什么" |
| **Identity对资源的解释机制** | 能说"日本想战略自主"，但不能说"为什么有巨大工业能力却不能自主" | Capability不是独立因子，是Identity对资源的解释结果 |
| **Strategy Selection黑箱** | 能画出策略空间，但不能解释"为什么选B不选C" | 策略空间到行动之间缺少决策机制 |
| **响应弹性** | 默认"主体变化=缓慢"，无法解释秒级反馈 | 反馈速度只是一维，缺少调整成本和过冲风险 |

## 二、核心修正：乘法→因果链

### 旧模型（初版方案）

```
Identity × Capability × Environment = Strategy Space
```

三个因子并列，乘在一起。问题：Capability和Environment都是**独立变量**，和Identity平起平坐。这会让ConStruct退化成现实主义国际关系理论（国家利益→资源→行动）。

### 新模型（修订版）

```
Identity
↓
解释环境（同一环境，不同身份→不同策略空间）
↓
定义能力可动员范围（同一资源，不同身份→冻结或释放）
↓
Strategy Space（逻辑上能选什么）
↓
Strategy Selection（Identity在操作层面展开自己→最终选什么）
↓
Action
```

这是**因果链**，不是乘法。Identity是起点，环境被它解释，能力被它冻结或释放，策略空间由它定义，最终选择由它在操作层面展开。

### 因果链的关键环节

**环节①：Identity解释环境**

```
同一环境：人口老龄化
↓
德国（秩序型/整合式）看到：移民（因为他者=可整合的资源）
日本（秩序型/冻结局）看到：自动化（因为他者=不可整合的威胁，必须内部解决）
中国（秩序型/整合式+绩效合法性）看到：产业升级（因为秩序维持=绩效，需要升级保增长）
```

环境是客观存在，但主体面对的不是"环境本身"，而是**"自己认为环境意味着什么"**。这个解释过程就是Identity对环境的过滤。

**环节②：Identity冻结或释放能力**

```
日本：巨大工业能力 × 战后身份（和平主义）
= 能力被冻结 → 只能防御性增强，不能进攻性扩张
= 策略空间：{军力提升✓, 主动攻击✗, 独立核武✗}

以色列：远少于日本的资源 × 生存身份
= 能力被释放 → 高度动员，一切可用于生存
= 策略空间：{先发打击✓, 核模糊✓, 全面动员✓}
```

Capability不独立存在。它是Identity对资源的**解释结果**——冻结或释放。

**环节③：Strategy Selection**

```
日本的策略空间：
{A:继续依附美国, B:战略自主, C:亚洲化, D:多元平衡}

为什么选A？
↓
Identity在操作层面展开自己：
- 精英结构 → 商界精英从战后就在美日联盟下积累利益（=L5维持机制的具体载体）
- 官僚惯性 → 外务省/防卫省的制度惯性（=L6秩序价值的制度形式）
- 历史记忆 → "在美国体系下我们成功了"（=L4建构来源的操作记忆）
- 政治联盟 → 自民党保守派联盟（=L6秩序价值的政治组织）
↓
四个操作层面的机制都在执行同一个指令：维持现有秩序
↓
选A（继续依附美国）——不是因为A"最好"，是因为A是Identity在操作层面唯一能顺畅展开的路径
```

Strategy Selection不是Identity**之外**的东西——它是Identity**之内**但**在操作层面**展开自己的过程。

## 三、DEL修正：从"环境数据层"到"身份解释环境"的转换机制

### 不是什么

❌ 不是"加一个数据库/API层"——数据量变了，但框架和数据的关系没变
❌ 不是"背景知识列表"——环境条件不是"背景"，是"经过身份过滤后变成策略空间边界条件的输入"
❌ 不是"环境×身份=约束"的乘法——环境不直接和身份相乘，环境**先被身份解释**，然后才变成约束

### 是什么

**DEL = 环境条件 × 身份解释 = 策略空间的边界条件**

核心因果链：

```
环境条件（客观存在）
↓
身份解释（Identity过滤：同一个环境，不同主体看到不同含义）
↓
策略空间边界（"在当前身份结构下，环境意味着我能做什么/不能做什么"）
```

### DEL的三层结构（保留，但注释修正）

```
DEL-1: 基础条件（慢变量，年度-十年更新）
├── 资源禀赋：能源储量/粮食自给率/水资源
├── 人口结构：老龄化率/移民比例/城市化率
├── 产业能力：制造业占比/技术自主度/供应链位置
├── 军事能力：核力量/海军吨位/军工产能
└── 财政约束：GDP/债务率/外汇储备/财政盈余
※ 这些是客观存在，但进入策略空间前必须经过身份解释

DEL-2: 策略变量（中速变量，月-季度更新）
├── 能源市场：油价/天然气价格/库存水平
├── 贸易格局：制裁清单/贸易伙伴占比/海运航线
├── 技术竞争：芯片产能/AI算力/卫星数量
├── 军事部署：基地分布/演习频率/武器交付
└── 金融条件：利率/汇率/资本流动/制裁豁免
※ 这些直接影响策略空间的短期边界

DEL-3: 事件脉冲（快变量，日-周更新）
├── 政治信号：领导人表态/政策文件/选举动态
├── 军事事件：冲突爆发/停火宣布/武器测试
├── 市场反应：油价波动/股市指数/资本异动
├── 舆论场：社交媒体趋势/媒体叙事/公众情绪
└── 外交动作：谈判进展/协议签署/联盟调整
※ 这些是Strategy Selection的即时触发条件
```

### DEL→约束的转换规则（修正版）

转换不是"DEL数据 × 身份 = 约束"的乘法，而是"DEL数据 → 身份解释 → 策略空间边界"的因果链：

| DEL变量 | 数据形式 | 身份解释 | 策略空间边界 |
|---------|----------|----------|------------|
| 油价$90 | 客观价格 | 特朗普（交易式）→ "停火有效"叙事可信度上升 | 维持协议的叙事窗口**打开** |
| 油价$90 | 客观价格 | 沙特（整合式）→ 财政压力减轻 | 国内秩序维持能力**增强** |
| 油价$90 | 客观价格 | 伊朗（互锁式）→ 制裁松绑但核门槛不能降 | 诈赢空间增大但根本让步✗ |
| 人口老龄化 | 客观比例 | 德国（整合式）→ 他者可整合=移民 | 策略空间包含大规模移民✓ |
| 人口老龄化 | 客观比例 | 日本（冻结局）→ 他者不可整合=自动化 | 策略空间排除大规模移民✗ |
| 日本军费$50B | 客观数字 | 日本身份（战后和平主义）→ 军费只能防御性 | 进攻性行动✗ / 独立核武✗ |
| 伊朗浓缩铀60%FEU | 客观库存 | 伊朗身份（互锁式/创伤=被入侵）→ 核技术维持门槛威慑 | 销毁高浓缩✗ / 突破核武✓（触发以色列阈值） |
| 伊朗浓缩铀60%FEU | 客观库存 | 以色列身份（互锁式/否定锚点=伊朗）→ 核门槛跨过=行动阈值降低 | 单独打击伊朗核设施✓ |

**同一个DEL数据，经过不同身份解释，产生不同的策略空间边界。** 这就是因果链的核心——环境不直接进入策略空间，身份是过滤器。

## 四、响应弹性（Response Elasticity）——替代"反馈速度分层"

### 为什么不是"速度"

"反馈速度"是一维概念——快或慢。但它忽略了两个关键维度：

- **调整成本**：美国调整政策成本极低（一条帖子→政策转向），中国调整政策成本极高（制度惯性→政策滞后）
- **过冲风险**：调整快+成本低=容易过冲（美国），调整慢+成本高=不容易过冲但容易滞后（中国）

### 三维定义

```
Response Elasticity（响应弹性）=
  反馈速度 × 调整成本 × 过冲风险
```

| 主体 | 反馈速度 | 调整成本 | 过冲风险 | 弹性特征 |
|------|---------|---------|---------|---------|
| 美国 | 快 | 低 | **高** | 高弹性高波动 |
| 中国 | 慢 | 高 | 低 | 低弹性低波动 |
| 欧盟 | 慢 | 中 | 低 | 低弹性高迟滞 |
| 金融市场 | 极快 | 极低 | **极高** | 极弹性极波动 |
| 以色列 | 快（军事） | 低（军事） | 中 | 行动弹性高，身份弹性低 |
| 伊朗 | 中 | 高 | 中 | 中弹性，革命惯性大 |
| 海湾国家 | 快（经济） | 低（经济） | 中 | 经济弹性高，身份弹性低 |

**弹性特征的含义：**

- **高弹性高波动**（美国）：能快速调整策略，但容易过冲——一条帖子→油价波动→选举概率变化→政策转向→又一条帖子→再转向。灵活但不稳定。
- **低弹性低波动**（中国）：调整稳定但容易滞后——经济数据已经变了，政策还在"稳"的框架里运行。稳定但不灵活。
- **低弹性高迟滞**（欧盟）：调整慢+共识成本高=迟滞严重。28国共识机制=弹性最低的制度形式。

### 弹性特征与Strategy Selection的关系

弹性特征直接影响Strategy Selection：

```
高弹性高波动主体（美国）：
策略选择更频繁变化 → 策略空间里的选项轮流被尝试 → 最终选择取决于"哪个选项刚好在过冲周期中处于上升阶段"

低弹性低波动主体（中国）：
策略选择高度稳定 → 一旦选定就长期维持 → 最终选择取决于"哪个选项最接近身份结构的核心指令"
```

这解释了为什么同样的策略空间，高弹性主体可能今天选B明天选C（过冲），低弹性主体可能十年都在A（惯性）。

### 与反馈回路的关系

响应弹性标注在三条现有反馈回路 + 新增两条回路上：

```
反馈回路①：行动→事件（L9 → L0）
弹性：随行动类型变化（军事=高弹性，制度=低弹性）

反馈回路②：存在→建构（L11 → L4）
弹性：极低（代际尺度，几乎无过冲风险）

反馈回路③：全球↔内部（L6 ⇄ L6）
弹性：随渠道变化（市场=极弹性，舆论=高弹性，制裁=中弹性）

反馈回路④：环境→身份解释→策略空间（DEL → Identity解释 → L9）
弹性：取决于主体本身的Response Elasticity

反馈回路⑤：行动→环境（L9 → DEL）
弹性：取决于行动类型（军事=高弹性/高波动，外交=中弹性，制度=低弹性）
```

## 五、Capability修正：从"独立层"到"Identity对资源的解释"

### 旧设计的问题

初版方案把L5h（硬能力）设计为L5（软能力）的**并行子层**——两者并列，各自独立。但这暗示Capability是独立因子，可以和Identity相乘。

### 修正

Capability不是独立层，是**Identity对客观资源的解释结果**。

```
客观资源（GDP/军费/人口/技术/地理）
↓
身份解释（Identity决定哪些资源可被动员、哪些被冻结）
↓
可动员能力范围
↓
进入Strategy Space的上限和下限
```

**不需要新增L5h子层**。硬能力数据（GDP/军费等）是DEL-1的一部分（基础条件），它们的"意义"取决于Identity的解释。在框架里的位置是：

```
DEL-1基础条件 → Identity解释 → Strategy Space边界
```

而不是：

```
L5h硬能力 → 与L5软能力并行 → 乘法公式
```

### 硬能力数据在框架中的呈现

硬能力数据不作为独立层级呈现，而是在分析时**标注在Strategy Space的边界条件上**：

```
日本Strategy Space：
上限：工业能力允许战略自主（客观条件）
下限：战后身份冻结进攻性军事能力（身份解释）
→ 实际策略空间 = {防御增强✓, 依附美国✓, 战略自主⚠（需要身份重构）, 进攻扩张✗}

以色列Strategy Space：
上限：资源有限但高度动员（身份释放）
下限：无下限——生存身份允许一切手段
→ 实际策略空间 = {全面动员✓, 先发打击✓, 核模糊✓, 和谈⚠（需要否定锚点不激活）}
```

## 六、Strategy Selection Engine

### 问题定义

策略空间已经画出来了——逻辑上能选什么。但主体最终选了哪一条路——**为什么选B不选C？** 这个环节是黑箱。

### 不是什么

❌ 不是新的L层——它是Identity在操作层面的展开，不是Identity**之外**的东西
❌ 不是独立变量——精英结构、官僚惯性、历史记忆、政治联盟都是Identity的具体实现
❌ 不是理性选择模型——主体不是"评估所有选项后选最优"，而是"Identity在操作层面唯一能顺畅展开的路径"

### 是什么

**Strategy Selection = Identity在操作层面的展开机制**

```
Identity（L2-L8定义"我们是谁"和"我们不能做什么"）
↓
Strategy Space（定义"逻辑上我们能选什么"）
↓
Strategy Selection（Identity通过四个操作层面机制展开自己）
├── 精英结构 → L5维持机制的具体载体（谁在做决策？他们的利益和身份绑定在哪里？）
├── 制度惯性 → L6秩序价值的制度形式（哪些路径有最低的制度摩擦力？）
├── 历史记忆 → L4建构来源的操作记忆（哪些路径和"过去成功"的叙事一致？）
├── 政治联盟 → L6秩序价值的政治组织（哪些路径能维持内部联盟的稳定？）
↓
Action（最终选择）
```

四个机制不是"额外变量"，它们是**Identity在操作层面的四种具体实现形式**：

| 操作机制 | 对应的L层 | 功能 | 例子 |
|---------|----------|------|------|
| 精英结构 | L5维持机制 | 载体——谁在维持秩序？ | 日本商界精英=美日联盟的利益承载者 |
| 制度惯性 | L6秩序价值 | 形式——制度在执行什么秩序？ | 日本外务省=美日联盟的制度化执行者 |
| 历史记忆 | L4建构来源 | 记忆——"我们怎么成功的？" | 日本战后成功=在美国体系下实现的 |
| 政治联盟 | L6秩序价值 | 组织——谁在组织秩序？ | 自民党保守派=维持现有联盟的政治力量 |

**同一个Identity，四个机制都在执行同一个指令：维持现有秩序。** 这就是为什么日本选"依附美国"——不是因为A"最好"，是因为A是Identity唯一能顺畅展开的路径。其他路径（战略自主/亚洲化）在操作层面都有制度摩擦力、精英利益冲突、历史记忆不一致、政治联盟不稳定。

### Strategy Selection的类型

不同身份类型有不同的Selection特征：

```
冻结局：高惯性Selection
- 制度惯性极强，精英结构高度绑定现有秩序
- Strategy Space里有多个选项，但Selection几乎总是选"维持现状"
- 例子：新加坡、日本

互锁式：高动员Selection
- 否定性锚点激活时，Selection急剧收窄——只有一个选项（行动）
- 例子：以色列（伊朗威胁激活→必须打击），伊朗（被入侵创伤激活→必须威慑）

交易式：高波动Selection
- 精英结构围绕交易组织，制度惯性低
- Strategy Space里的选项频繁切换——取决于"哪个交易当前最有利"
- 例子：特朗普（今天选停火，明天可能选制裁）

整合式：共识Selection
- 精英结构和政治联盟需要维持共识
- Selection倾向选"所有利益集团都能接受的中间路线"
- 例子：欧盟（28国共识=弹性最低的Selection机制）
```

### DEL在框架中的位置（修正）

```
DEL数据（客观条件）
↓
Identity解释（L2-L8过滤）
↓
Strategy Space边界条件
↓
Strategy Selection（Identity操作层展开）
↓
Action
```

每个DEL变量与Identity交叉时，产生**不同的解释和不同的策略空间边界**：

```
DEL-1（人口老龄化）× 德国Identity（整合式）→ 策略空间包含大规模移民
DEL-1（人口老龄化）× 日本Identity（冻结局）→ 策略空间排除大规模移民
DEL-2（油价$90）× 特朗普Identity（交易式）→ 维持协议的叙事窗口打开
DEL-2（油价$90）× 伊朗Identity（互锁式）→ 诈赢空间增大但根本让步不可能
```

### 反馈回路（修正）

原有三条 + 新增两条，**每条标注Response Elasticity**：

```
反馈回路①：行动→事件（L9 → L0）
弹性特征：随行动类型（军事=高弹性高波动，制度=低弹性低波动）

反馈回路②：存在→建构（L11 → L4）
弹性特征：极低弹性极低波动（代际尺度）

反馈回路③：全球↔内部（L6 ⇄ L6）
弹性特征：随渠道（市场=极弹性极波动，舆论=高弹性高波动，制度=低弹性低波动）

反馈回路④：环境→身份解释→策略空间（DEL → Identity → L9）
弹性特征：取决于主体本身的Response Elasticity
（高弹性主体=环境变化迅速反映到策略空间；低弹性主体=环境变化缓慢渗透）

反馈回路⑤：行动→环境（L9 → DEL）
弹性特征：取决于行动类型
（军事行动=高弹性/高波动 → 环境迅速变化；制度改革=低弹性/低波动 → 环境缓慢变化）
```

## 八、CAP：ConStruct Analysis Pipeline

### 为什么不是IPCEAFU

IPCEAFU这个命名暗示它是"框架的组成部分"（六个层级）。但它不是本体论，是方法论。

很多理论失败的原因就是把**分析流程**包装成**世界结构**。L0-L11回答"世界是什么"，CAP回答"怎么分析"。两者必须分开。

### CAP前置步骤：信号检测（Signal Detection）

在进入IPSAFU之前，有一个前置步骤——**信号检测**。它的功能不是分析，是**决定要不要分析**。

```
信号检测（Signal Detection）
↓
方向一致性判断（Direction Consistency）
↓
进入 IPSAFU
```

#### 为什么需要前置步骤

单个反常事件可能是噪音，但如果多个反常事件同时出现且指向同一个方向——这不是噪音，这是信号。

但不是所有"异常"都值得串联。只有**违背主体正常行为逻辑的事件**才是信号。

#### 信号检测的三步流程

**第一步：症状识别（Symptom Identification）**

筛选标准：只有"正常逻辑下不该发生的事"才进入信号池。

```
✓ 欧洲经济疲软还加息 → 违背"疲软时应降息刺激"的正常逻辑
✓ 日本零利率三十年突然加息 → 违背冻结局"维持现状"的正常逻辑
✓ 避险资产不避险（黄金比特币跌）→ 违背"动荡时避险资产涨"的正常逻辑
✗ 某国GDP增长2% → 不违背任何正常逻辑，不是信号
✗ 某国按预期降息 → 符合正常逻辑，不是信号
```

**第二步：方向一致性判断（Direction Consistency）**

问：这些信号是否指向同一个底层变化？

```
欧洲加息 → 防止资本外逃 → 美元体系虹吸压力
日本加息 → 防止资本外逃 → 美元体系虹吸压力
亚太股市涨+货币跌 → 外资拉高出货撤退 → 美元体系虹吸压力
黄金比特币跌 → 资金被美元体系抽走 → 美元体系虹吸压力
SpaceX顶风上市 → 资本寻找危机逃生舱 → 美元体系泡沫风险

→ 五个信号全部指向同一方向：美元体系承压，全球资本重新分配
→ 不是五个独立怪事，是同一个结构变化的五种症状
→ 进入IPSAFU分析
```

如果方向不一致——信号指向不同方向——那就是独立噪音，不需要强行串联。

```
某国加息 + 某国降息 + 某国政局动荡 + 某国自然灾害
→ 指向不同方向
→ 四个独立事件，不是结构性症状
→ 不需要进入IPSAFU
```

**第三步：信号→CAP的衔接**

信号检测确认了"这里有一个结构性变化需要诊断"之后，进入IPSAFU：

```
信号检测结果：
"五个异常同时指向'美元体系承压→全球资本重新分配'"
↓
进入 I（Identity）→ 分别诊断美国/欧盟/日本的身份结构
↓
进入 P（Purpose）→ 各方在维持什么秩序、防止什么恐惧
↓
进入 S（Strategy Space）→ 同一环境（美元高利率），三个Identity解释出三个不同的策略空间
↓
……
```

#### 信号检测的核心原理

**单个信号可能是噪音，但方向一致的多信号是结构性症状。**

这个原理和Strategy Selection的一致性检测是**同一个逻辑的宏观/微观版本**：

```
微观版（Strategy Selection一致性检测）：
日本加息 + 军费增长 + 半导体重建 + 能源多元化 + 供应链调整
→ 五个动作指向同一方向（扩张策略空间）
→ 不是零散政策反应，是Identity系统性调整

宏观版（信号检测方向一致性）：
欧洲加息 + 日本加息 + 亚太股涨币跌 + 黄金比特币跌 + SpaceX上市
→ 五个信号指向同一方向（美元体系承压）
→ 不是五个独立怪事，是同一结构变化的五种症状
```

底层逻辑相同：**多个异常指向同一方向 = 结构性变化信号**。区别只是观察尺度——微观看单个主体的多个动作，宏观看多个主体的多个异常。

---

### CAP定义

```
前置：信号检测（Symptom Detection）→ 方向一致性判断 → 决定是否进入IPSAFU

I  Identity      主体是谁（L1-L3 + L7-L8定位）
   ↓
P  Purpose       为什么存在（L4 + L8 + L10定位）
   ↓
S  Strategy Space 逻辑上能选什么（Identity解释环境 → 定义能力可动员范围 → 策略空间边界）
   ↓
A  Action        最终选了什么（Strategy Selection → Identity操作层展开）
   ↓
F  Feedback      结果如何（Response Elasticity标注 × 反馈回路）
   ↓
U  Update        主体是否更新（环境驱动微调 / 身份重构）
```

注意：**C（Capability）和E（Environment）不再是独立步骤**——它们被吸收进了S（Strategy Space）的计算过程中。Capability = Identity对资源的解释结果；Environment = Identity解释后的策略空间边界条件。

### CAP作为自检清单

每次分析完之后，按IPSAFU顺序检查是否遗漏：

```
前置：信号检测
  ✓ 是否识别了"违背主体正常行为逻辑"的异常事件？
  ✓ 这些异常是否指向同一方向？
  ✓ 如果方向一致 → 确认结构性变化 → 进入IPSAFU

I ✓ 主体身份已定位？（L2连续性类型？L3存在方式？L8创伤？L7他者？）
P ✓ 存在目的已诊断？（维持什么秩序？防止什么恐惧？）
S ✓ 策略空间已画出？（环境条件×身份解释=边界？能力可动员范围？）
A ✓ 最终选择已解释？（Strategy Selection机制？精英结构/制度惯性/历史记忆/政治联盟？）
F ✓ 响应弹性已标注？（反馈速度/调整成本/过冲风险？）
U ✓ 更新机制已识别？（环境驱动的微调？身份重构的可能？）
```

缺了哪个环节，补哪个。CAP是分析者的自检工具，不是框架层级。

## 九、分析工作流升级

### 旧工作流（v1.2）

```
事件 → 框架标签归类 → 输出分析
```

### 中期工作流（方法论反思后）

```
事件 → 历史探查 → 框架定位 → 输出分析
```

### v2.0工作流（修订版）

```
信号检测 → 方向一致性判断 → 确认结构性变化 → 事件史探查 → Identity定位 → 环境条件注入（经Identity解释）→ Strategy Space计算 → Strategy Selection解释 → 输出诊断
```

具体步骤：

1. **信号检测**：识别"违背主体正常行为逻辑"的异常事件，判断多个异常是否指向同一方向
2. **事件史探查**：2015→2018→2026，每个动作的因果链
3. **Identity定位**：在L2-L8中定位（连续性类型？存在方式？创伤锚点？他者系统？）
4. **环境条件注入**：DEL数据是什么？Identity如何解释这些数据？（同一油价$90，特朗普看到叙事窗口，伊朗看到诈赢空间）
5. **Strategy Space计算**：Identity定义的策略空间边界——哪些路逻辑上走得通，哪些不可能
6. **Strategy Selection解释**：策略空间里有多个可行选项时，为什么选了这条路？（精英结构/制度惯性/历史记忆/政治联盟）
7. **输出诊断**：在当前Identity结构+环境条件下，哪些路走得通，哪些路逻辑上不可能

## 十、完整因果链模型

```
前置：信号检测（Symptom Detection）
├── 症状识别：筛选"违背主体正常行为逻辑"的异常事件
├── 方向一致性判断：多个异常是否指向同一底层变化？
├── 如果一致 → 确认结构性症状 → 进入因果链
└── 如果不一致 → 独立噪音 → 不需要强行串联

Identity（L2-L8）
↓ 定义"我们是谁"和"我们不能做什么"
↓
解释环境（DEL → Identity过滤）
↓ 同一环境，不同身份看到不同含义
↓
定义能力可动员范围（客观资源 → Identity冻结或释放）
↓ 同一资源，不同身份→冻结（日本）或释放（以色列）
↓
Strategy Space（逻辑上能选什么）
↓
Strategy Selection（Identity在操作层面展开）
├── 精英结构 = L5维持机制的载体
├── 制度惯性 = L6秩序价值的制度形式
├── 历史记忆 = L4建构来源的操作记忆
├── 政治联盟 = L6秩序价值的政治组织
↓ 四个机制执行同一指令：维持现有秩序
↓
Action（最终选择）
↓
Feedback（Response Elasticity标注）
├── 反馈速度
├── 调整成本
├── 过冲风险
↓
Update（环境驱动微调 / 身份重构）
```

**信号检测与Strategy Selection一致性检测的统一逻辑：**

```
宏观（信号检测）：
多个主体的多个异常 → 指向同一方向 → 结构性症状

微观（Strategy Selection一致性检测）：
单个主体的多个动作 → 指向同一方向 → Identity系统性调整

底层原理相同：多异常方向一致 = 结构性变化信号
区别：宏观看跨主体症状，微观看单主体行动一致性
```

## 十二、不做什么

1. **不把CAP当成框架层级**——IPSAFU是分析流程（方法论），不是世界结构（本体论）
2. **不把DEL做成纯数据库**——没有身份解释的转换规则，数据库对框架无贡献
3. **不把Capability做成独立L层**——硬能力是DEL数据经Identity解释的结果，不是并行子层
4. **不重新编号L层**——v1.2的L0-L11编号保持，扩展而非替换
5. **不改变框架对外呈现**——读者看到的还是"核心分析方法：国家的行为不仅受利益驱动，更受'我们是谁'和'秩序如何延续'的深层需求塑造……"，因果链/DEL/Strategy Selection是内部工具
6. **不让ConStruct退化成现实主义**——乘法模型（Identity × Capability × Environment）会退化成"国家利益→资源→行动"，因果链模型不会
