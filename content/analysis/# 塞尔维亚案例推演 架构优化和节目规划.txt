# 塞尔维亚案例推演：用优化后架构跑一遍

以下是用优化后的7步架构，对**塞尔维亚（武契奇访华背景下）**进行的完整推演。

---

## 模块1：场景与行为体概览

**场景名称**：塞尔维亚的多极摆荡——欧盟、中国、俄罗斯之间的身份困境  
**核心矛盾**：塞尔维亚的欲望是“被欧洲承认是大国”，但其主体性建构（摆荡式）和科索沃执念使其无法满足欧盟条件；中国和俄罗斯提供替代支点，但无法填补认同空洞。  
**时间点**：2025年（武契奇访华期间）

| 行为体 | 目的列表（必然* / 手段性） | 时间偏好 | 主体性模式 | 他者欲望（类型+对象） | 决策者摘要 |
|--------|---------------------------|---------|-----------|---------------------|-----------|
| **塞尔维亚** | 1. 维持对科索沃的主权主张*<br>2. 加入欧盟（获取经济红利）<br>3. 与中国/俄罗斯保持友好（平衡西方） | 高（科索沃问题不能等） | 摆荡式（欧盟↔俄↔中） | 进取性→欧盟（想成为“正常欧洲国家”）<br>工具性→中国（要支持，不想成为） | 武契奇：选举威权+党机器；个人权力绑定于“科索沃不丢”+平衡外交 |
| **欧盟** | 1. 稳定西巴尔干*<br>2. 防止俄罗斯/中国影响力扩张<br>3. 维护扩盟程序的信誉 | 中（选举周期+扩盟疲劳） | 整合式（但内部裂隙） | 防御性→俄罗斯/中国（不让他们填补真空） | 成员国分歧+欧委会；法德主导，匈牙利否决权 |
| **中国** | 1. 一带一路经济布局*<br>2. 在欧洲获得政治支点<br>3. 不直接挑战欧盟但扩大存在 | 极低（长期战略） | 整合式 | 进取性→全球多极化（成为体系内的一极） | 党的领导+共识决策；时间视野极长，不索取认同 |
| **俄罗斯** | 1. 阻止北约东扩*<br>2. 维持巴尔干传统影响力<br>3. 展示“并非孤立” | 高（乌克兰战争压力） | 摆荡式（帝国焦虑） | 防御性→北约（不被排除出欧洲安全体系） | 普京+安全会议；冒险风格，资源受限 |
| **科索沃** | 1. 维持独立地位*<br>2. 获得国际承认（尤其是欧盟）<br>3. 防止塞尔维亚回归 | 极高（生存恐惧） | 互锁式（否定塞尔维亚=存在） | 镜像性→塞尔维亚（欲望塞不承认自己） | 执政精英+北约保护；独立=合法性来源 |

## 模块2：目的结构冲突

### 内部冲突（塞尔维亚）

| 目的 | 冲突类型 | 判断依据 |
|------|---------|---------|
| 维持科索沃主权主张 ↔ 加入欧盟 | ❌ 严重互斥 | 欧盟要求“科索沃关系正常化”=实质承认科索沃地位 |
| 与中国/俄罗斯友好 ↔ 加入欧盟 | ⚠️ 中度张力 | 欧盟要求对俄制裁、对华“去风险”，塞尔维亚拒绝 |
| 维持科索沃主张 ↔ 经济发展 | ⚠️ 中度张力 | 科索沃僵局吓退外资，入欧停滞 |

**自动判断**：摆荡式+多目的（3个核心目的相互矛盾）→ 高概率内部互斥，摆荡是症状而非策略。

### 跨行为体冲突

| 对 | 冲突类型 | 判断依据 |
|----|---------|---------|
| 塞尔维亚 ↔ 欧盟 | ⚠️ 交易式张力 | 塞尔维亚要入欧但不肯付代价（科索沃+制裁）→ 欧盟扩盟疲劳加剧 |
| 塞尔维亚 ↔ 科索沃 | ❌ 互锁式无解 | 双方主体性互锁：塞否定科独立=塞认同；科否定塞主张=科存在 |
| 塞尔维亚 ↔ 俄罗斯 | ✅ 便利伙伴 | 泛斯拉夫认同+能源依赖，但俄国在削弱 |
| 塞尔维亚 ↔ 中国 | ✅ 便利伙伴 | 中国提供实利，不索取认同 |

**关键诊断**：塞尔维亚与科索沃的冲突是逻辑无解（互锁式），与欧盟的冲突是代价问题（可谈判但价太高）。

## 模块3：底盘与约束审查

### 地理层
- 内陆国家，无出海口
- 科索沃位于南部，占领土15%，人口180万（90%阿尔巴尼亚族）
- 多瑙河航运（对欧出口通道）
- 被北约国家包围（克罗地亚、匈牙利、罗马尼亚、保加利亚、北马其顿、阿尔巴尼亚、黑山、波黑）

**约束强度**：⚠️ 中等。内陆限制经济，但军事威胁低（北约包围但无入侵意愿）。

### 经济层

| 子维度 | 内容 | 约束强度 |
|--------|------|---------|
| GDP与体量 | 约750亿美元（人均~1.1万），巴尔干中等 | 低 |
| 贸易结构 | 对欧盟占60%（主要德意），对中国5%但增长快 | 高（欧盟依赖） |
| 能源安全 | 90%依赖俄气（通过TurkStream），中国投资可再生能源 | 高（俄依赖） |
| 供应链 | 汽车零部件、金属加工，嵌入欧盟产业链 | 高（欧盟绑定） |
| 制裁韧性 | 未对俄制裁→保留贸易，但失去欧盟部分市场 | 中 |
| 综合判断 | **经济上深度依赖欧盟，但能源和投资转向中国/俄** | — |

### 历史层
- 1389年科索沃战役（民族神话）
- 一战后南斯拉夫创立（整合式实验）
- 1999年北约轰炸（创伤记忆，“被西方背叛”）
- 2008年科索沃单方面独立（国际法不公感）
- 对“大国承认”有执念，对“被排除出欧洲”有深层恐惧

### 文化层
- 东正教（与俄罗斯同源，与西方天主教/新教区隔）
- 斯拉夫传统（与俄罗斯、波黑塞族、黑山共享）
- 反奥斯曼、反北约的叙事代际传承
- “科索沃是塞尔维亚的耶路撒冷”——不可谈判的能指

### 民族层
- 塞尔维亚族83%，阿尔巴尼亚族~7%（集中在科索沃）
- 科索沃问题本质是民族+宗教+领土三重锁定
- 塞族在波黑塞族共和国、黑山、克罗地亚有跨境存在 → 区域影响力工具

**底盘总评**：塞尔维亚被**四条锁链**固定——欧盟经济锁、俄能源锁、科索沃身份锁、内陆地理锁。任何路径都必须同时处理这四条。

---

## 模块4：约束条件

### 军事层
- 军队约2.5万人，无空军（2015年后未更新）
- 4个俄制米格-29中队（老旧）
- 科索沃有北约驻军（KFOR，约3700人）
- 无核武器，无导弹威慑
- 与北约保持“和平伙伴关系”，但公众反北约情绪强烈

**约束强度**：⚠️ 中低。塞尔维亚无能力武力改变科索沃现状，北约提供底线保护（但对塞是威胁）。

### 制度层
- 欧盟候选国（2012年），谈判进度极慢（2021年开启谈判组）
- 入盟条件：科索沃关系正常化、对俄制裁、司法改革、反腐败
- 与俄罗斯有自贸协定、能源协议
- 与中国有自贸协定（2024年生效）、“一带一路”备忘录
- 联合国安理会第1244号决议（承认南联盟对科索沃主权）→ 中国的支持来源

**约束强度**：高。塞尔维亚被制度多重绑定，但主动利用制度缝隙（不选边站，同时保留所有选项）。

## 模块6：路径树与验证

### 路径1：最终入欧（放弃科索沃主张）

| 组件 | 内容 |
|------|------|
| 概率 | 极低 |
| 必要条件 | 塞尔维亚承认科索沃独立或“关系正常化”（实质承认）；对俄制裁；司法/媒体改革 |
| 行动学判断 | 塞尔维亚摆荡式建构无法接受“放弃科索沃”——那是核心能指的断裂。武契奇的个人权力绑定于“没有放弃科索沃”，任何承认都会导致政权崩溃。 |

**验证结果**：
- ❌ R3：摆荡式+渐进路径冲突（“承认科索沃”不是渐进，是全盘否定）
- ❌ R11：互锁式无解（塞尔维亚与科索沃主体性互锁）
- ⚠️ R7：决策者偏差（武契奇个人目的与国家目的绑定于科索沃）

**综合**：❌ 严重矛盾。该路径逻辑上不可能。

---

### 路径2：彻底倒向中俄（放弃入欧）

| 组件 | 内容 |
|------|------|
| 概率 | 低 |
| 必要条件 | 欧盟扩盟彻底停滞+中国投资大幅增加+俄罗斯战争胜利或停战 |
| 行动学判断 | 塞尔维亚精英层（包括武契奇）的文化、资产、子女教育仍深度绑定欧洲，且经济上无法脱欧（60%出口）。倒向中俄意味着精英层的自我否定——摆荡式不会全盘否定自己，只会否定“当前的妥协策略”。 |

**验证结果**：
- ❌ R2：时间偏好矛盾（塞尔维亚精英层时间偏好高，但倒向中俄是长期战略转向）
- ❌ R4：经济互毁（失去60%出口市场，中国无法填补）
- ⚠️ R8：决策权力脆弱性（武契奇的权力基础依赖西方资金/投资流入）

**综合**：❌ 严重矛盾。经济上不可能，精英层不接受。

---

### 路径3：维持多极摆荡（现状+）

| 组件 | 内容 |
|------|------|
| 概率 | 高 |
| 必要条件 | 欧盟继续容忍塞尔维亚“两面下注”；中国持续投资但不索取认同；俄罗斯不垮但也不要求选边；科索沃问题不升级 |
| 行动学判断 | 这是塞尔维亚的“舒适区”——摆荡式建构的最优解：从每个他者那里拿好处，但不为任何一个改变核心立场。中国、俄罗斯、欧盟都接受（尽管不满）。武契奇的个人权力最大化。 |

**验证结果**：
- ⚠️ R10：冻结局脆弱性？（塞尔维亚不是冻结局，不适用）
- ⚠️ R6：症状维护者约束（科索沃执政精英、塞民族主义政党、俄能源公司从僵局获利）

**综合**：⚠️ 警告。可行但依赖外部条件：欧盟不施压、中国持续投、俄罗斯不垮、科索沃不升级。任一条件破裂，路径失效。

---

### 路径4：科索沃问题“芬兰化”（事实上独立+塞默认）

| 组件 | 内容 |
|------|------|
| 概率 | 低→中（长期看可能） |
| 必要条件 | 塞尔维亚获得某种“补偿”（如加速入欧、中国投资、科索沃塞族高度自治）；武契奇退位或权力基础变化 |
| 行动学判断 | 这是唯一可能的“软退出”方案。塞尔维亚不正式承认科索沃独立，但停止阻挠其国际参与（如加入联合国教科文组织、欧盟项目）。科索沃获得事实独立，塞保留面子。 |

**验证结果**：
- ⚠️ R3：摆荡式+渐进路径冲突（“默认”可能是摆荡式能接受的最大渐进）
- ❌ R11（弱化）：互锁式松动（科索沃的互锁式依赖塞的公开否定，默认可能抽空认同）
- ⚠️ R7：决策者偏差（需要武契奇下台或权力重组）

**综合**：⚠️ 警告。逻辑上可能，但需要外部强力推动（如欧盟+美国联合施压，同时给塞足够补偿）和内部领导层更替。中短期内概率低，长期可能。

## 模块7：症状诊断

| 症状维护者 | 类型 | 如何维护冲突 | 对路径的影响 |
|-----------|------|-------------|-------------|
| 塞尔维亚民族主义政党（SNS、激进党等） | 身份型+制度型 | 科索沃是选举动员核心议题；任何妥协=政治自杀 | 阻塞路径1、4 |
| 科索沃执政精英（自决运动等） | 身份型+物质型 | 独立=合法性来源；与塞低烈度冲突提供执政理由 | 阻塞路径1、4 |
| 俄罗斯（能源公司+安全机构） | 物质型+身份型 | 科索沃僵局使塞依赖俄能源/政治支持；泛斯拉夫认同 | 阻塞路径1，助推路径3 |
| 欧盟扩盟官僚机构 | 制度型 | 扩盟进程的存续依赖“候选国”存在；僵局提供改革理由 | 助推路径3（维持现状） |
| 中国（一带一路项目） | 物质型 | 塞作为“欧洲支点”需要稳定但不需解决科索沃 | 助推路径3，不鼓励路径1/2/4 |

**核心诊断**：科索沃僵局有**至少5个症状维护者**，覆盖物质、身份、制度三类。这就是为什么任何“解决”路径（1、4）都被严重阻塞，而“维持现状”路径（3）有强大的结构性支持。

## 综合判断

| 维度 | 结论 |
|------|------|
| 最可能路径 | **路径3：维持多极摆荡（现状+）** |
| 主要矛盾 | 塞尔维亚的摆荡式建构 vs 欧盟的整合式要求；塞尔维亚与科索沃的互锁式锁定 |
| 关键约束 | 经济上依赖欧盟（60%出口），能源上依赖俄，但政治上无法接受科索沃条件 |
| 症状维护者 | 5个，覆盖三类，形成强大的“僵局维持联盟” |
| 变数 | 武契奇之后的领导层；欧盟扩盟政策是否彻底放弃西巴尔干；俄罗斯在乌克兰战争后的地位；科索沃内部政治（是否出现“第二代”不依赖互锁的领导人） |

**综合等级**：⚠️ **警告** —— 当前路径可行但高度依赖外部条件，长期看结构性矛盾未解决，任何外部冲击（欧盟放弃、俄垮台、塞内乱）都可能导致系统失稳。

## 武契奇访华的意义（在框架中的定位）

用这套框架重新解读武契奇在北京：

| 维度 | 解读 |
|------|------|
| 对塞尔维亚 | 在欧盟、俄、中之间增加一个支点，使摆荡更稳定（不依赖单一他者） |
| 对中国 | 巩固一个“在欧洲不选边站”的伙伴，展示一带一路韧性，牵制欧盟 |
| 对欧盟 | 信号：你不给我想要的（科索沃+入欧），我有别处可去 |
| 对俄罗斯 | 补充（俄在削弱，中国填补经济功能，但不替代文化-宗教认同） |
| 对科索沃 | 塞尔维亚获得外部支持→更不可能妥协→互锁更紧 |
| 对路径3 | 加强——中国提供更多“好处”，塞对欧盟依赖相对下降，但未改变根本结构 |

**一句话**：武契奇在北京不是在“选择东方”，而是在**为塞尔维亚的多极摆荡增加一个配重块**，让摆荡的幅度变小、稳定性变高。这是摆荡式建构的理性选择，不是身份转向。
# 塞尔维亚系列节目规划

## 一、系列定位与核心叙事

**系列名称**（暂定）：`巴尔干棋局：塞尔维亚的多极摆荡`

**核心叙事主线**：
> 一个小国，在大国缝隙中，如何靠“不选边站”活成赢家？但当所有大国都开始逼你选边时，这个游戏还能玩多久？

**系列调性**：
- 地缘政治+行动学框架（米塞斯+拉康）+现场感（武契奇访华作为切入点）
- 节奏紧凑、视觉化强、结论锋利
- 每期结尾留钩子，引导观众用工具验证

**目标观众**：
- 地缘政治爱好者（尤其对巴尔干、中欧关系、大国博弈感兴趣）
- 关注塞尔维亚/武契奇的人群
- 对“小国生存策略”有代入感的观众（台湾、新加坡、波罗的海等国观众）

## 一、工具“藏”的艺术：从“可见”到“可感”

### 核心原则
- **观众不需要知道工具存在**，只需要感受到“这个频道的分析很深刻、逻辑自洽、结论可验证”。
- **工具是编剧，不是演员**。视频是成品，工具是生产线。

### 具体藏法

| 维度 | 做法 |
|------|------|
| **品牌名** | 不用“地缘推演台”，用“GeoDepth”“Strategic Anatomy”“The Constraint Lab”等，暗示有方法论但不透露是工具 |
| **视觉风格** | 使用自定义地图、箭头、约束标签（如“R1地理封锁”），但这些标签看起来像是专家的分析代码，而非软件输出 |
| **验证标签** | ✅/⚠️/❌ 可以作为固定视觉元素，但不出现“工具自动验证”字样，而是说“基于我们的约束分析框架” |
| **路径树** | 手绘风格或定制动画，不露出输入框、下拉菜单等UI元素 |
| **数据来源** | 引用公开报告、新闻、历史文档，不说是“工具预设” |
| **引流到工具** | 不在视频中提工具，只在描述区、社区帖子、付费会员区提供“深度推演包”（含预设JSON+分析模板），让高级用户自己发现 |

### 例外情况
- 当你推出**付费高级版**或**定制分析服务**时，可以做一个独立的“工具介绍视频”，但放在另一个频道或会员专区。
- 公开频道保持“纯内容”调性，工具作为幕后英雄。

---

## 二、双平台内容策略：英文（YouTube）vs 中文（B站）

### 核心内容资产共享
- **同一套分析框架**（米塞斯+拉康+约束验证）
- **同一套案例库**（塞尔维亚、新加坡、巴尔干、中日等）
- **同一套视觉资产**（地图、路径树模板、验证标签）

### 差异化：语言、叙事风格、时长、标题党

| 维度 | YouTube（英文） | B站（中文） |
|------|----------------|-------------|
| **受众画像** | 西方地缘迷、政策分析师、学者、东欧侨民 | 国内国际关系爱好者、上班族、学生 |
| **叙事风格** | 冷静、学术化、引用理论（米塞斯、拉康），重逻辑链 | 故事化、人物驱动（武契奇）、标题刺激，重代入感 |
| **时长** | 12-18分钟（深度分析） | 8-12分钟（快节奏） |
| **标题示例** | “Why Serbia Won’t Pick a Side” | “武契奇在北京：小国的摆荡艺术” |
| **钩子前3秒** | 地图+数据卡片+“Here’s why...” | 冲突画面+反问句+“你可能不信……” |
| **理论引用** | 直接提“Mises”“Lacan”“praxeology” | 用“行动学”“欲望结构”或干脆不提名字，只说“我们的分析框架” |
| **视觉密度** | 高（图表、引注、路径树） | 中（更多人物画面、表情包、梗图） |
| **评论区互动** | 理性辩论、引战科索沃地位 | 情绪共鸣、玩梗、@朋友来看 |

## 一、工具架构需要优化的三个核心点

### 1. 增加“防御性否定”作为他者欲望的第四种类型
现有三种（进取性、防御性、镜像性）无法精准描述美国在巴尔干的欲望结构。美国的欲望不是“不被当成某种东西”（防御性），而是“**阻止他者成为某种东西**”——这是一种**否定性的力量投射**。

| 类型 | 定义 | 案例 | 工具字段 |
|------|------|------|---------|
| 进取性 | 想成为他者承认的X | 中国“成为强国” | 他者欲望=进取，对象=X |
| 防御性 | 不想被他者当成Y | 新加坡“不是华人国家” | 他者欲望=防御，对象=Y |
| 镜像性 | 欲望他者不欲望自己 | 以色列-哈马斯 | 他者欲望=镜像，锁定对象=Z |
| **否定性** | 阻止他者成为/拥有W | 美国阻止中俄在巴尔干扎根 | 他者欲望=否定，目标=W，手段=军事/制裁 |

**实现方式**：在行为体建模中，他者欲望下拉菜单增加“否定性”，并关联一个“否定目标”（如“中国在巴尔干的基建”）。

### 2. 支持“多极摆荡”（N≥4）
之前的摆荡模型只支持两极或三极。塞尔维亚实际是**四极摆荡**（欧盟、中国、俄罗斯、美国），每个极的引力类型不同：
- 欧盟：认同引力（想成为“欧洲国家”）
- 中国：交易引力（要钱不要身份）
- 俄罗斯：情感引力（东正教、泛斯拉夫）
- 美国：**规避引力**（不想被制裁/轰炸）

**实现方式**：在行为体层增加“摆荡极列表”，用户可添加多个极，每个极可标注引力类型（认同/交易/情感/规避）。工具自动判断路径的“摆荡可行性”。

### 3. 增加“跨时空创伤锚点”作为约束层的一种特殊类型
1999年大使馆轰炸是中塞共同的创伤记忆，这种锚点会影响两国长期的行为选择。它不属于地理、经济、历史、文化、民族中的任何一类，但确实是一个硬约束。

**实现方式**：在“底盘”中增加第六层——“**创伤锚点**”。字段包括：事件、涉及行为体、情感强度（1-10）、对当前路径的影响（如“任何包含‘美国军事重返巴尔干’的路径自动标红”）。

### 4. 验证规则新增两条
基于科索沃战争的金融解读：
- **R14（货币战争约束）**：如果路径涉及“欧元挑战美元”，且存在行为体美国+否定性欲望，则任何“欧元成为巴尔干主导结算货币”的路径自动❌
- **R15（创伤锚点约束）**：如果存在创伤锚点（如1999轰炸），且路径包含“该锚点行为体的军事回归”，则自动⚠️或❌

| 主体性建构模式 | 单选 | 是 | 整合式/摆荡式/交易式/冻结局/互锁式 | 如何定义“我是谁” |
| 他者欲望类型 | 单选 | 是 | 进取性/防御性/镜像性/否定性 | 欲望的指向结构 |
| 他者欲望对象 | 文本 | 条件必填 | 行为体名称或“无” | 欲望针对的“他者” |
| 否定目标 | 文本 | 条件必填 | 当类型=否定性时 | 具体阻止什么（如“中国基建”） |

**主体性建构模式详解**：

| 模式 | 定义 | 行为特征 | 案例 |
|------|------|---------|------|
| 整合式 | 把矛盾容纳进稳定象征秩序 | 长期战略一致，可短期妥协 | 中国、美国（冷战）、欧盟 |
| 摆荡式 | 在几个极端之间来回，无法稳定 | 政策剧烈摆动，全盘否定前路线 | 日本、塞尔维亚、俄罗斯 |
| 交易式 | 用利益交换替代身份建构 | 灵活但漂移，缺乏战略锚定 | 法塔赫、亚伯拉罕协议后的阿拉伯国 |
| 冻结局 | 主动冻结一切身份流动 | 防御性、排斥外部情感输入 | 新加坡、波黑（外生） |
| 互锁式 | 靠否定他者来定义自己 | 和解即自我毁灭 | 以色列-哈马斯、科索沃-塞尔维亚 |

**他者欲望类型详解**：

| 类型 | 定义 | 欲望结构 | 案例 | 工具字段示例 |
|------|------|---------|------|-------------|
| 进取性 | 想成为他者承认的X | “我要成为你认可的那个样子” | 中国“成为强国” | 类型=进取，对象=美国/国际社会 |
| 防御性 | 不想被他者当成Y | “我不要被你当成那个东西” | 新加坡“不是华人国家” | 类型=防御，对象=中国/马来西亚 |
| 镜像性 | 欲望他者不欲望自己 | “我要你否定我，这样我才能存在” | 以色列-哈马斯 | 类型=镜像，锁定对象=对方行为体 |
| 否定性 | 阻止他者成为/拥有W | “我不要你成为那个东西” | 美国阻止中俄在巴尔干扎根 | 类型=否定，目标=中俄基建，手段=军事/制裁 |

### 2.4 决策者变量（可选但推荐）

| 字段 | 类型 | 选项/格式 | 说明 |
|------|------|----------|------|
| 身份角色 | 文本 | 如“总统+安全会议” | 谁在做决策 |
| 权力基础 | 单选 | 选举/党机器/军方/世袭/技术官僚/革命合法性 | 靠什么维持权力 |
| 制度约束 | 文本 | 自由填写 | 什么限制决策空间 |
| 决策风格 | 单选 | 审慎/冒险/意识形态驱动/务实/反应型 | 决策倾向 |
| 个人目的与国家目的的偏差 | 文本 | 自由填写 | 是否存在系统性偏差 |

## 三、底盘约束层（六层）

| 层级 | 字段 | 类型 | 说明 | 约束强度 |
|------|------|------|------|---------|
| 1. 地理 | 文本 | 必填 | 地形、距离、资源、战略要地 | 终极硬约束 |
| 2. 经济 | 结构化对象 | 推荐 | 见下方子维度 | 利益约束 |
| 3. 历史 | 文本 | 推荐 | 历史记忆、创伤叙事 | 叙事约束（长周期） |
| 4. 文化 | 文本 | 推荐 | 文化传统、行为模式 | 行为约束（中周期） |
| 5. 民族 | 文本 | 推荐 | 民族构成、身份裂隙 | 边界约束 |
| **6. 创伤锚点（新增）** | 数组 | 可选 | 见下方定义 | 情感硬约束 |

### 3.1 经济层子维度

| 子维度 | 类型 | 说明 |
|--------|------|------|
| GDP与体量 | 文本 | 经济体量对比 |
| 贸易结构与依赖 | 文本 | 相互依赖程度、不对称方向 |
| 能源安全 | 文本 | 能源来源、运输路线、被卡风险 |
| 供应链/产业链 | 文本 | 关键产业的全球位置、脆弱节点 |
| 制裁韧性 | 文本 | 面对经济制裁的承受能力 |
| 综合判断 | 文本 | 经济层面的关键不对称 |

### 3.2 创伤锚点（新增）

**定义**：历史上对行为体产生深刻情感冲击、持续影响当前决策的事件。与“历史层”的区别是：创伤锚点**涉及具体行为体之间的互动**，且情感强度高、持续时间长。

**字段**：

| 字段 | 类型 | 说明 |
|------|------|------|
| 事件名称 | 文本 | 如“1999年北约轰炸中国驻南联盟大使馆” |
| 涉及行为体 | 数组 | 受害方、加害方 |
| 情感强度 | 1-10 | 1=轻微，10=民族创伤 |
| 对当前路径的影响 | 文本 | 如“任何包含美国军事重返巴尔干的路径自动标红” |

**示例**：
```json
{
  "event": "北约轰炸中国驻南联盟大使馆",
  "actors": ["中国", "美国", "塞尔维亚"],
  "intensity": 9,
  "constraint": "路径包含'中美在巴尔干全面合作'触发严重警告"
}
```

## 四、路径层（推演与验证）

### 4.1 路径结构

每条路径包含：

| 字段 | 类型 | 说明 |
|------|------|------|
| 标签 | 文本 | 路径名称 |
| 概率 | 单选 | 高/中/低/极低 |
| 必要条件 | 文本 | 需要哪些外部条件 |
| 行动学判断 | 文本 | 逻辑推理过程 |
| 子路径 | 数组 | 嵌套结构（最多两层） |

### 4.2 验证规则体系（v4）

#### 现有规则（保留）

| 规则 | 内容 | 触发条件 |
|------|------|---------|
| R1 | 地理约束冲突 | 地理含“无纵深/封锁”+路径含“快速/闪电/突破” |
| R2 | 时间偏好矛盾 | 行为体时间偏好极高/高 + 路径要求长期等待 |
| R3 | 摆荡式+渐进路径冲突 | 行为体摆荡式 + 路径含“渐进/温和/调适” |
| R4 | 经济互毁约束 | 高经济相互依赖 + 路径含“全面对抗/脱钩” |
| R5 | 核威慑约束 | 存在核威慑 + 路径含“全面战争/核冲突” |
| R6 | 症状维护者约束 | 症状维护者≥2 + 路径含“和平解决/和解” |
| R7 | 决策者偏差约束 | 决策者目的偏差 + 路径要求长期一致性 |
| R8 | 决策权力脆弱性 | 选举制+派系+高时间偏好 + 路径要求长期承诺 |
| R9 | 冒险型+核风险 | 决策风格冒险 + 存在核威慑 + 路径含“升级/试探” |

#### 新增规则（v4）

| 规则 | 内容 | 触发条件 |
|------|------|---------|
| R10 | 冻结局脆弱性 | 主体性=冻结局 + 外部正向情感输入（如乡愁文化产品） |
| R11 | 互锁式无解 | 两个行为体互锁式 + 路径含“和解/关系正常化” |
| R12 | 防御性欲望与认同输入冲突 | 他者欲望=防御性 + 路径要求“强化身份认同” |
| R13 | 外生冻结局维护依赖 | 冻结局类型=外生 + 外部支持衰减变量 |
| **R14** | **货币战争约束（新增）** | 路径涉及“欧元挑战美元” + 行为体美国+否定性欲望 + 路径含“欧元成为主导结算货币” → ❌ |
| **R15** | **创伤锚点约束（新增）** | 存在创伤锚点（情感强度≥7） + 路径包含“锚点加害行为体军事回归” → ⚠️ 或 ❌ |

## 五、输出结构（五模块报告）

### 模块1：场景与行为体概览
- 场景名称、核心矛盾、时间点
- 每个行为体：名称、目的列表、时间偏好、主体性模式、他者欲望类型+对象、决策者摘要

### 模块2：目的结构冲突
- 内部冲突（基于主体性模式的自动判断）
- 跨行为体冲突（自动+手动）
- 详细互斥分析（用户填）

### 模块3：底盘与约束审查
- 地理层、经济层（6子维度）、历史层、文化层、民族层
- **创伤锚点列表（新增）**
- 军事层、制度层
- 外部场域列表

### 模块4：路径树与验证
- 每条路径：标签、概率、条件、判断、子路径
- 每条路径的验证结果（✅/⚠️/❌）+ 触发规则
- 综合判断（基于所有路径的最严重等级）

### 模块5：症状诊断
- 症状维护者列表（谁、如何维护、类型）
- 对路径的潜在影响
