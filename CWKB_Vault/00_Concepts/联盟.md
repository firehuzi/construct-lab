# 联盟

## 定义

> [!definition] 核心定义
> 两个或多个主体通过正式/非正式协议，在安全/经济/意识形态领域建立的合作关系。联盟不是友谊——是交易性互惠或Identity互补。

## ConStruct映射

| 层级 | 映射 |
|------|------|
| L2 | 交易局/秩序局——联盟是维持连续性的外部支持 |
| L3 | 互惠交换机制——贡献→保护/利益 |
| L5 | 联盟内精英的利益绑定 |
| L6 | 条约制度化（北约第五条、美日安保） |
| L7 | 联盟=他者结构的具体化——盟友=正向他者，对手=否定性他者 |
| L8 | 联盟是Identity的延伸还是Identity的约束？——美国=延伸，日本=约束 |

## 观察指标

1. **联盟可靠性**：危机时盟友是否履行承诺
2. **联盟不对称性**：谁贡献更多——不对称=依附
3. **联盟排他性**：能否同时与对手合作
4. **联盟弹性**：分歧是否会摧毁联盟
5. **联盟成本**：维持联盟需要付出什么

## 典型案例

| 主体 | 表现 | 备注 |
|------|------|------|
| 美国 | 联盟网络创造者 | 交易式——可以退出（2018），也可以回来 |
| 日本 | 安全依附美国 | 冻结局——联盟=冻结条件的一部分 |
| 欧盟 | 内部联盟=身份本身 | 整合式——联盟=共识=身份，退出=死亡 |

## 反例
