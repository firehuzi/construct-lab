## ConStruct World Model Knowledge Base（CWKB）v2.1

> 版本：v2.1 | 日期：2026-06-19
> 基于：CWKB v2.0 + 优化建议
> 目标：可被AI调用、可持续演化、支持策略空间分析的世界模型


## 核心定位

传统知识库回答：

```
发生了什么？
```

ConStruct知识库回答：

```
这个事件改变了谁？为什么改变？改变方向是什么？
```

新闻 = 输入 → 主体 = 上下文 → ConStruct = 推理层 → 策略空间变化 = 输出

## 四、Layer 2：历史文献

> 回答：世界如何走到今天？


### 来源

- FRUS（美国对外关系文件集）——美国外交档案汇编，1861年至今
- National Security Archive（国家安全档案馆）——超9万份解密文件
- NSDDD v3.0——118个国家1987-2025年的660份国家安全战略文件
- 外交档案、战略文件、解密文献
- 凯南等早期战略家公共领域著作（Project Gutenberg）


### Historical Event Chain

为每个关键历史时期建立事件链：

```yaml
冷战形成:

1945 雅尔塔会议
  ↓
1947 杜鲁门主义
  ↓
1948 柏林危机
  ↓
1949 北约成立
  ↓
1955 华约成立

关键转折点:
  - 1947年3月12日：杜鲁门主义提出
  - 1948年6月24日：柏林封锁开始
  - 1949年4月4日：北约签署

ConStruct意义:
  L2: 秩序型连续性确立（两极格局）
  L6: 全球秩序分裂为两个阵营
  L7: 美苏互为敌人他者
```
