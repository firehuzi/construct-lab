# 05_Academic

> ★ **本目录当前【声明为空】。** 这份 README 说明它该装什么、为什么现在空、以及填它需要什么。
> 它是 S1.4 的产物：**让「空」变成被声明的、可机器查的状态**，而不是靠人记得它还没做。

## 该装什么

学术层：与结构诊断相关的**同行评议文献**（国际关系、政治学、社会学、认知科学）。

## 为什么现在空

从未开始。**而它是本框架最缺的一类支撑** —— 框架的每个判据都该能追到文献或反例。

## 填它需要什么

① 每条：作者 ／ 年份 ／ 期刊 ／ DOI ／ **它支持或反驳本框架的哪一条**；② 优先补**反例**（《L2L8 判据与反例》里那些反例现在都是我写的，没有文献支撑）。

## ⛔ 不许拿什么填

⛔ 不许拿「某研究支持这一观点」这种没有具体出处的说法充数。
