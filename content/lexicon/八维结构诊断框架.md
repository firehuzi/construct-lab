# 八维结构诊断框架 (8-Dim Structural Diagnostic)

> 国别结构诊断的八维雷达：每个维度对应一个 L 层，值来自构型对照矩阵的序数编码。八维是分析结构，全部有真实指标，不能留空。

**所属层**: 跨层度量框架（覆盖 L2/L3/L5/L6/L7/L8/L9/L10）
**适用构型**: 所有主权国家 / 政治实体（当前仅美/中/日/俄有完整矩阵）
**运作机制**:
- **身份连续性 (L2)** ← `Identity连续性`：历史印记跨越断裂的承继强度。高=锚点稳固可预测；低=身份焦虑驱动补偿。示例：日本5 / 美国4 / 中国3 / 俄罗斯2。
- **存在方式 (L3)** ← `深层Identity`：自认的文明秩序类型（山巅/天下/第三罗马/国体）。决定对"正常世界"的想象。示例：日本5(国体) / 美中俄均4。
- **方法灵活性 (L9)** ← `方法轨迹类型`：切换/组合方法的能力。高=适应性强；低=单向锁定刚性。示例：美国5(线性+方法切换) / 俄罗斯2(单向锁定)。
- **维持机制 (L5)** ← `当前方法阶段`：当前靠什么维持内部秩序（交易式/复兴/武力恢复/冻结局）。示例：美国3(交易式) / 中4(复兴) / 俄4(武力恢复) / 日4(冻结局)。
- **方向扩张性 (L10)** ← `当前方向`：战略方向 ↑扩张/→维持/↓收缩。映射 L10 六型。示例：美3(→) / 中4(↑) / 俄4(↑)。
- **秩序价值 (L6)** ← `深层Identity`（同源再编码）：对秩序的赋值——全球领袖/区域中心/内部完整。示例：美国5(全球领袖) / 日本3(内部)。
- **他者复杂度 (L7)** ← `他者结构`：敌友结构化方式（四重/三重/双极/双）。高=分而治之；低=零和锁定。示例：美国4(四重) / 其余3。
- **恐惧深度 (L8)** ← `核心恐惧`：什么会"杀死"主体（终结/消除/双重复合=深度）。恐惧是最底层驱动。示例：美4(终结) / 俄4(消除) / 中日3。

**典型主体**:
- 美/中/日/俄：八维全 8/8 填充（USA 档案四国对比矩阵）。
- IRN/UKR/PRK 等：无四国对比矩阵 → 雷达诚实标"无构型数据"，柱图/趋势仍出真实战争记录。

**常见误解**:
- 误解1: "雷达值是客观打分" — 实际情况: 是构型矩阵分类值的**序数编码**，不是测量。发布须标图注"序数编码构型矩阵"。
- 误解2: "结构轴（L3/L5/L6/L8）是空的占位" — 实际情况: 早期版本留空，已纠正；这四维也来自矩阵对比列（深层Identity/当前方法阶段/核心恐惧），八维全有真实指标。
- 误解3: "八维对所有国家都可用" — 实际情况: 四国对比矩阵只在 USA 档案，目前仅四国出 8/8；其余国家需补构型对照矩阵模块才能扩覆盖。
