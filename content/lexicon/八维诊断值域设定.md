# 八维诊断值域设定 (Ordinal Encoding of 8-Dim)

> 八维雷达的每个值，都是构型对照矩阵分类文本的序数编码（0–5），不是测量值。本文档定义九个量表与匹配规则。

**所属层**: 度量机制（支撑 L1-L10 雷达的赋分规则）
**适用构型**: 所有国别诊断雷达
**运作机制**:
- **编码本质**: 输入=矩阵单元格分类文本（如"强（建国文本+宪法框架 250 年）"）；输出=0–5 整数。是分析师判断的可视化，非客观打分。
- **九量表完整定义**:
  | 量表 | 键→值 | 维度 |
  |------|-------|------|
  | SCALE_CONT | 极强:5 / 强:4 / 中:3 / 弱:2 | 身份连续性 |
  | SCALE_MODE | 国体:5 / 山巅:4 / 制度实验:4 / 例外:4 / 天下:4 / 第三罗马:4 / 复兴:4 | 存在方式 |
  | SCALE_TRAJ | 线性+方法切换:5 / scope递增式:4 / 循环式:3 / 单向锁定:2 | 方法灵活性 |
  | SCALE_MAINT | 交易式:3 / 复兴:4 / 武力恢复:4 / 冻结局:4 / scope:4 / 循环:3 / 单向锁定:4 / B:4 | 维持机制 |
  | DIR | ↑:4 / →:3 / ↓:2（兼容 扩张/维持/收缩） | 方向扩张性 |
  | SCALE_ORD | 山巅:5 / 例外:5 / 天下:4 / 国体:3 / 第三罗马:3 | 秩序价值 |
  | SCALE_HEIR | 四重:4 / 三重:3 / 双极:3 / 双:2 | 他者复杂度 |
  | SCALE_FEAR | 终结:4 / 孤立:3 / 无法建立:3 / 失控:3 / 消除:4 / 双重复合:4 | 恐惧深度 |
  | SCALE_CONT_TYPE | 主体型:5 / 秩序型:4 / 混合型:3 | （预留，未用于当前八维） |
- **匹配规则**（代码真相）:
  1. `parse_matrix` 定位含"维度/美国/俄罗斯"的表头行，按国家列提取单元格。
  2. `match_scale` 子串匹配量表键（兼容括号后缀，如"强（…）"→命中"强"=4）。
  3. 方向用 `encode_dir`：优先 ↑/→/↓，否则匹配 扩张/维持/收缩。
  4. 未命中 → 默认 3（中性），图注透明声明。
  5. 四国回退：主角无矩阵且属四国之一 → 回退 USA 档案四国对比矩阵。
- **缺失与降级**: 无矩阵→8 维全 None 标"无构型数据"；单维度缺→该轴 None；**绝不填默认伪装**。
- **刻度**: 0–5，5 层网格；中性点=3；多数量表最低 2（存在即 ≥2），1 留极端情形。

**典型主体**: 美/中/日/俄（八维全填充，值见八维结构诊断框架）
**常见误解**:
- 误解1: "5 分=最好" — 实际情况: 5 是"最强/最典型"，非价值褒贬。如俄罗斯"身份连续性 2"是客观断裂，不是"差"。
- 误解2: "不同维度可横向比大小" — 实际情况: 同维度跨国可比；跨维度（如身份连续性 vs 恐惧深度）量纲不同，不可直接比。
- 误解3: "值会自动更新" — 实际情况: 值来自静态构型矩阵，除非分析师修订矩阵单元格，否则不变；活库（--live）只接密度/UCDP，不接管雷达编码。
