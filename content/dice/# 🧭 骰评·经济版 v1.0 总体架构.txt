# 🎲 L3：骰子层（核心创新层）

👉 “从结构 × 解释中抽取路径”

---

## 🎯 输入

```text
经济现象 + 结构场 + 理论层
```

例如：

> 房价上涨

---

## 🎲 骰子做什么？

不是随机词

而是：

> **随机生成一条“解释路径”**

---

## 🧭 路径结构

```text
结构场（1~2个）
  ↓
理论视角（1个）
  ↓
因果链展开（3~5步）
  ↓
结论方向
```

---

## 🎲 示例

### 输入：房价上涨

骰子结果：

```text
结构场：金融 + 需求
理论：马克思

路径：

信贷扩张 → 资产化 → 居住商品化 → 阶级分层强化 → 房地产成为剩余价值吸收器
```

---

### 再掷一次：

```text
结构场：价格 + 叙事
理论：行为经济学

路径：

预期上涨 → 羊群效应 → FOMO → 价格自我实现 → 泡沫形成
```

---

👉 核心：

> 同一现实 = 多条因果路径

---

# ✍️ L4：输出层（骰评生成）

👉 “最终评论形态”

---

## 🎯 标准输出结构

### ① 开场（现象锚定）

* 现实描述一句话

---

### ② 结构路径（核心）

* 1条骰子路径展开（主线）

---

### ③ 对照路径（增强）

* 1~2条不同理论路径

---

### ④ 冲突点

* 哪些解释互相矛盾但同时成立

---

### ⑤ 收束（结构洞察）

* 一个“不可还原结论”

---

## 🧪 示例输出形态

```text
房价上涨看起来是市场行为，但实际上它同时是三种机制叠加的结果。

在马克思主义视角中，这是资本对居住空间的再吸收过程……
（路径1）

而在行为经济学中，这更像是预期驱动的自我实现……
（路径2）

制度经济学则指出……
（路径3）

三者并不冲突，它们描述的是同一结构的不同层级。

真正的问题不是“为什么涨”，而是：
当所有解释都成立时，谁在定义现实？
```

# 五、骰子层 Prompt（L3）

👉 核心创新层

```text id="l3_prompt"
You are a causal path generator.

Input:
- Economic structure fields
- Selected theory lens

Task:
Generate 1 causal reasoning chain.

Rules:
- Select 1–2 structural fields
- Use selected theory lens
- Build step-by-step causal chain (3–6 steps)
- End with an interpretive insight
- Do NOT summarize, only construct reasoning path
```

---

# 六、输出层 Prompt（L4）

```text id="l4_prompt"
You are an economic essay generator.

Input:
- causal path(s)
- competing interpretations

Task:
Write a structured economic commentary.

Structure:
1. Phenomenon introduction
2. Primary causal path
3. Alternative interpretation path (optional)
4. Tension between explanations
5. Final insight (non-reductive conclusion)

Tone:
- analytical
- non-dogmatic
- layered
```

# 🧠 二、核心页面（app/page.tsx）

```tsx id="page"
"use client";

import { useState } from "react";
import InputBox from "@/components/InputBox";
import StructureGrid from "@/components/StructureGrid";
import TheorySelector from "@/components/TheorySelector";
import DicePath from "@/components/DicePath";
import OutputPanel from "@/components/OutputPanel";

export default function Home() {
  const [topic, setTopic] = useState("");
  const [result, setResult] = useState(null);
  const [loading, setLoading] = useState(false);

  const generate = async () => {
    setLoading(true);

    const res = await fetch("/api/generate", {
      method: "POST",
      body: JSON.stringify({ topic }),
    });

    const data = await res.json();
    setResult(data);
    setLoading(false);
  };

  return (
    <main className="p-10 max-w-4xl mx-auto">

      <h1 className="text-2xl font-bold mb-6">
        骰评 · Economic Atlas Engine
      </h1>

      <InputBox value={topic} setValue={setTopic} onGenerate={generate} />

      {loading && <p>骰子旋转中...</p>}

      {result && (
        <>
          <StructureGrid data={result.structure_fields} />
          <TheorySelector data={result.theory_lenses} />
          <DicePath path={result.dice_paths?.[0]} />
          <OutputPanel content={result.output} />
        </>
      )}
    </main>
  );
}
```

# ⚙️ 三、核心 API（app/api/generate/route.ts）

```ts id="api"
import { NextResponse } from "next/server";
import { buildPrompts } from "@/lib/prompts";

export async function POST(req: Request) {
  const { topic } = await req.json();

  const prompts = buildPrompts(topic);

  const response = await fetch("https://api.openai.com/v1/chat/completions", {
    method: "POST",
    headers: {
      "Authorization": `Bearer ${process.env.OPENAI_API_KEY}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify({
      model: "gpt-4o-mini",
      messages: [
        { role: "system", content: prompts.system },
        { role: "user", content: topic }
      ],
      temperature: 0.9
    })
  });

  const data = await response.json();
  const text = data.choices[0].message.content;

  return NextResponse.json(JSON.parse(text));
}
```

# 🎲 五、骰子逻辑（lib/diceEngine.ts）

```ts id="dice"
export function rollDice(fields: string[], lenses: string[]) {
  const randomField = () =>
    fields[Math.floor(Math.random() * fields.length)];

  const randomLens =
    lenses[Math.floor(Math.random() * lenses.length)];

  return {
    fields: [randomField(), randomField()],
    lens: randomLens,
  };
}
```
