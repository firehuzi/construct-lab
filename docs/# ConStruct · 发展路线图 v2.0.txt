# ConStruct · 发展路线图 v2.0

> 认知框架验证优先，而非技术基础设施优先


## 核心判断

这个项目最大的难点不是技术，而是：

```
认知框架是否成立
```

因此路线图应该按照认知验证→规则验证→主体验证→系统验证→预测验证逐层演进，而不是按照知识库→网站→AI的软件工程顺序。


## Phase 0（0-3个月）：ConStruct Alpha

**目标：证明框架有效，而非证明技术有效。**

此阶段不追求：自动采集、AI Agent、RAG、Web产品。全部不重要。

### 核心任务

#### 1. 建立20个核心主体档案（目标：20个主体 + 200个关键事件）

| 类别 | 主体 |
|------|------|
| 大国 | 美国、中国、俄罗斯、欧盟 |
| 中等强国 | 德国、法国、英国、日本、韩国、印度 |
| 中东 | 伊朗、以色列、沙特、土耳其 |
| 国际组织 | 北约、联合国、东盟、金砖 |
| 企业 | 台积电、ASML、OpenAI |

#### 2. 每个主体档案包含

- Identity（L2-L8定位）
- Strategy Space（当前策略空间）
- Response Elasticity（响应弹性特征）
- Event Chain（关键事件链）

### 验证标准

完成20个主体 + 200个关键事件档案后，评估框架能否解释过去3年的主要地缘事件。如果框架在50%以上事件上解释失效，则需修正框架设计。


## Phase 1（3-6个月）：ConStruct Beta

**目标：验证信号检测能力。**

### 核心任务

#### 1. 运行Signal Detector

每天处理50-100条新闻，测试哪些事件最终成为战略信号、哪些只是噪音。

#### 2. 建立Signal Library

| 信号类型 | 示例 |
|----------|------|
| 货币信号 | 日本加息、人民币贬值 |
| 军费信号 | 德国军费增长、日本防卫预算 |
| 能源信号 | 沙特人民币结算、欧洲能源转型 |
| 联盟信号 | 北约东扩、金砖扩员 |
| 技术信号 | 芯片出口管制、AI监管 |
| 制裁信号 | 对俄制裁、对伊制裁 |

### 验证标准

建立500个信号样本。如果信号识别准确率低于60%，则需修正信号规则库。


## Phase 2（6-12个月）：ConStruct Gamma

**目标：建立行为预测能力。**

### 核心任务

#### 1. 建立Action Predictor

输入：主体状态 + 策略空间 + 约束 + 激励 → 输出：最可能行动

示例：
```
日本：能源风险↑ 军事压力↑ 货币自主↑
→ 预测：增加军费、推动核能、产业回流
```

#### 2. 持续验证

建立至少1000个预测案例，统计命中率。

### 验证标准

预测命中率超过65%。如果低于此标准，需修正预测模型。


## Phase 3（1-2年）：ConStruct Delta

**目标：建立动态世界模型——主体不再孤立，形成主体网络。**

### 核心任务

建立关系图谱，使事件影响能够自动传播：

```
美国制裁
    ↓
中国
    ↓
稀土出口
    ↓
欧洲车企
    ↓
德国经济
```

### 验证标准

模型能够解释主要国际事件的系统性影响。


## Phase 4（2-3年）：ConStruct Omega

**目标：建立策略空间模拟器。**

用户输入情景（如“台湾出现危机”），系统自动推演各方反应的概率分布，并生成未来30天、90天、1年的多个路径推演。


## 终局（3-5年）：World Model Engine

用户输入情景（如“台湾出现危机”），系统自动推演各方反应的概率分布：

```
美国可能动作：72%
中国可能动作：81%
日本可能动作：65%
```

并生成未来30天、90天、1年的多个路径推演。


## AI的角色定位

### 错误做法

```
让AI直接分析世界
```

LLM会漂移，今天说A明天说B，且所有人都有GPT，这不是护城河。

### 正确做法

```
ConStruct = 世界模型（结构）
AI = 推理CPU（执行）
```

**AI不是世界模型本身，而是世界模型的加速器。** 把AI定位为：

- 知识库建设工人
- 事件标注员
- 档案维护员
- 预测实验员


## 竞争护城河分析

| 护城河类型 | 构筑周期 | 被复制难度 |
|-----------|---------|----------|
| 代码/技术栈 | 2-4周 | 低 |
| UI/产品设计 | 2-3个月 | 低 |
| 主体档案库 | 2-3年 | 高 |
| 事件链库 | 2-3年 | 高 |
| 信号规则库 | 2-3年 | 高 |
| 预测数据集（含失败记录） | 3-5年 | 极高 |

**真正需要几年积累的是：**

- 主体档案库（谁在扩张、谁在收缩）
- 事件链库（什么事件触发了什么变化）
- 信号规则库（什么信号值得关注）
- 预测数据集（含失败记录）

这些才是未来World Model Engine的“参数”。代码10天能搭出来，但参数需要几年积累。


## 开发优先级建议

```
2026
主体档案库 + 事件雷达

2027
行为预测器 + 世界状态图

2028
策略空间模拟器

2029+
World Model Engine
```

每一步都能独立产出价值，且不会陷入“先造一个超级复杂系统再验证”的陷阱。
