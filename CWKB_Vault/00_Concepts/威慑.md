# 威慑

## 定义

> [!definition] 核心定义
> 通过制造不可承受的代价预期，阻止他者采取特定行动。不是防御（抵挡攻击），而是预防（使攻击不被考虑）。

## ConStruct映射

| 层级 | 映射 |
|------|------|
| L2 | 秩序局——威慑是秩序维护的工具 |
| L3 | 否定性反馈机制——越界=不可承受代价 |
| L5 | 精英对威慑可信度的维护 |
| L6 | 威慑制度（核门槛、红线声明） |
| L7 | 威慑对象=否定性他者；威慑可信度=他者对你能力的评估 |
| L8 | 威慑是Identity的投射——被威慑者必须相信你会使用 |

## 观察指标

1. **威慑能力**：实际摧毁/惩罚能力
2. **威慑可信度**：使用意志被对方评估为多高
3. **威慑稳定性**：危机中威慑是否升级或崩溃
4. **威慑替代**：是否有非威慑手段达到同等效果

## 典型案例

| 主体 | 表现 | 备注 |
|------|------|------|
| 美国 | 核保护伞+常规力量 | 交易式威慑——可信度靠信誉成本维持 |
| 伊朗 | 核门槛威慑 | 互锁式威慑——不拥核但保持门槛=永远有升级选项 |
| 以色列 | 模糊核威慑 | 互锁式威慑——不承认但所有人都知道 |
| 朝鲜 | 核武+导弹 | 自主局威慑——核武=生存保障=Identity |
