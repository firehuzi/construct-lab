# 02_History

> ★ **本目录当前【声明为空】。** 这份 README 说明它该装什么、为什么现在空、以及填它需要什么。
> 它是 S1.4 的产物：**让「空」变成被声明的、可机器查的状态**，而不是靠人记得它还没做。

## 该装什么

历史层：与 47 个主体相关的**历史记录**——条约、战争、领土变更、关键转折点。

## 为什么现在空

本项目的历史材料现在**散在 `actors/` 与 `ConStruct_Archive/` 的叙述里**，没有按主体归集的时间线。而《主体类型框架》指出「历史记忆是 L4 建构来源的操作记忆」—— 要消费它必须有可读的字段，而现在是散文。

## 填它需要什么

① 每个主体一条**带日期的事件线**；② 每条事件带**出处**（这是 F1 的同一条规矩）；③ 至少覆盖该主体的**核心创伤锚点**（L8 的输入）。

## ⛔ 不许拿什么填

⛔ 不许拿模型生成的历史概述填 —— 历史事件必须有出处，否则它与「编」没有区别。

---

**审计**：`python -B construct-engine/cwkb_audit.py` 会把「声明为空」与「没人管的空」分开报。
