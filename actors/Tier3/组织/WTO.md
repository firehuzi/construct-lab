## 模块一：基础信息

| 字段 | 内容 |
|------|------|
| 主体名称 | 世界贸易组织（World Trade Organization / WTO） |
| 成立时间 | 1995年1月1日（前身GATT：1947年） |
| 成员国 | 166国 |
| **连续性类型** | **规则秩序型**——Identity="全球自由贸易的规则制定者与争端裁判者" |
| **构型** | **整合式衰退版**——成员一致同意=规则制定，争端解决=规则执行。但规则制定（多哈回合）自2001年以来停滞；规则执行（上诉机构）自2019年以来瘫痪。核心功能的两个支柱都被架空 |
| **存在方式** | **"规则存在，但没有法官来执行"**——WTO的贸易规则仍然有效，但争端解决的上诉机构（最高法官）被US单方面阻塞——意味着"有法律，没有最高法院" |
| **核心恐惧** | **被彻底绕过**——各国通过双边/区域贸易协议（CPTPP/RCEP/IPEF）取代WTO规则，使WTO成为"可以被忽略的遗产系统" |
| **身份一句话** | 我是全球化的法律框架——但两个最大的贸易国（US/CN）都在用"国家安全例外"绕过我的规则。我有法律——但没有法官来执行它。 |


## 模块二：两个支柱的坍塌

**支柱一：多边贸易谈判。** 多哈回合（2001年启动）旨在更新全球贸易规则——农业补贴+服务贸易+知识产权。2008年谈判破裂——此后20年没有任何重大的多边贸易协议完成。WTO的"立法功能"已经停滞了二十年。

**支柱二：争端解决。** 2019年——US开始阻止上诉机构（WTO的最高法院）的新法官任命。三年后，所有法官任期结束，没有替代——上诉机构完全瘫痪。WTO仍然有"初审法院"（专家组）——但任何一方可以上诉到不存在的上诉机构——使裁决无法生效。

**两个支柱同时坍塌=WTO作为"规则+裁判"的双重功能架空。** 各国仍然在WTO框架内协商——但实质性的贸易摩擦已经转移到双边渠道（US-CN关税战、US-EU数字税谈判、CN-EU电动汽车关税）。


## 模块三：构型——整合式衰退版

| | UN整合式衰退版 | **WTO整合式衰退版** |
|---|---|---|
| 瘫痪机制 | 大国否决权 | **上诉机构被US单方面瘫痪** |
| 瘫痪后果 | 安理会不能做任何大国反对的事 | **"有法律，没有最高法院"** |
| 绕过方式 | 大国绕过联合国发动行动 | **双边/区域贸易协议取代WTO** |
