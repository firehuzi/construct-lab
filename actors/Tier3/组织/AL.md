## 模块一：基础信息

| 字段 | 内容 |
|------|------|
| 主体名称 | 阿拉伯国家联盟（League of Arab States / جامعة الدول العربية） |
| 成立时间 | 1945年3月22日 |
| 成员国 | 22国（从摩洛哥到阿曼——横跨北非+中东+东非） |
| **连续性类型** | **象征性联盟型**——每一个阿拉伯国家都声称希望"阿拉伯统一"——但没有一个阿拉伯国家愿意放弃主权来实现它 |
| **构型** | **协调平台（更弱版）**——比ASEAN更弱。ASEAN有地理集中性+共同经济关切。阿盟有共同语言/文化/宗教——但地理跨度极大（8000km），经济差异极大（卡塔尔人均GDP $80,000+ vs 也门 $600），内部敌对（1979-1989年埃及被开除，2011年叙利亚被暂停，2017-2021年沙特等封锁卡塔尔） |
| **存在方式** | **"决议是阿盟唯一的产品"**——阿盟不产出政策执行、不产出军事协调、不产出经济一体化。它产出"表达共同关切的决议"——用强烈的语言，但没有任何执行机制 |
| **核心恐惧** | **不被任何成员国需要——连"共同出席"都失去意义**——如果大国（沙特/埃及/阿联酋）都选择不在阿盟框架内协商 |
| **身份一句话** | 我是阿拉伯世界的联合国——但比联合国还弱。联合国至少有大国否决权来维持相关性（因为大国关心安理会决议）。阿盟没有任何成员国的否决权——因为阿盟的决议对任何成员国都没有约束力。 |


## 模块二：阿盟悖论——统一的话说得最多，统一的行动做得最少

**"阿拉伯统一"是所有阿拉伯领导人的口头禅——也是所有阿拉伯领导人最怕实现的东西。**

为什么？因为"阿拉伯统一"在修辞中是"恢复过去的荣光"——在现实中是"谁来当哈里发"。纳赛尔在1958-1961年尝试了阿拉伯联合共和国（埃及+叙利亚），结果叙利亚政变退出——证明"统一"不是理想不够好——是具体利益冲突使统一在物理上不可行。

阿盟的结构完美反映了这个悖论：决议需要一致同意——给每个成员国"我们参与了决策"的仪式感——但没有任何执行机制——确保没有成员国的利益被真正损害。

**阿盟的最大历史性行动是两个"开除"：** 1979年开除埃及（萨达特和以色列和平→1989年恢复）。2011年暂停叙利亚（阿萨德镇压→2023年恢复）。两者都花了十年以上的时间来"恢复"——而在这十年以上，被开除的国家继续存在，毫不受影响。


## 模块三：不是在阿盟——在GCC

**真正的阿拉伯世界的协调发生在GCC（海湾合作委员会）**——沙特+阿联酋+卡塔尔+科威特+阿曼+巴林。GCC = 有钱的阿拉伯国家俱乐部。他们不需要通过22国阿盟来做决策——他们通过6国GCC来做决策，然后在阿盟仪式性地通知其他成员国。

**和ASEAN的对照：**

| | ASEAN | 阿盟 |
|---|---|---|
| 地理集中性 | 有——东南亚 | **无——摩洛哥到阿曼=8000km** |
| 经济同质性 | 中——新兴市场 | **极端差异——卡塔尔$80,000 vs 也门$600** |
| 共同安全威胁 | 有——CN-US竞争 | **有——但内部敌人（伊朗/以色列）比外部共识更大** |
| 实质性决策出口 | 无——但东盟确实有协调功能 | **有——GCC（海湾六国）才是真正的决策平台** |
