# ConStruct Lab · 场景耦合图 v1.0

> 日期：2026-06-22
> 基于：审查反馈——从"10个优秀分析"→"1个全球系统"
> 核心发现：10个场景天然分层——引擎层/资源层/投射层，形成闭合环路

## 三层结构

```
【引擎层】 驱动整个系统运转
  ⟳ 场景9 AI与芯片 + 场景10 全球金融 ⟳
    │                              │
    ▼ 需燃料                        ▼ 需融资
【资源层】                          
  场景6 北极（航道/稀土）            
  场景8 非洲（铜/钴/锂）            场景3 俄乌（能源过渡）
  场景4 中东（石油/天然气）          
    │                              
    ▼ 燃料供给→引擎加速→权力扩张      
【投射层】 大国竞争的表现场
  场景1 台海 · 场景2 南海
  场景5 印巴 · 场景7 拉美
```

## 核心闭合环：算力 → 资源 → 金融 → 权力 → 算力

```
AI与芯片战争（场景9）
    │ 需要关键矿产（镓/锗/稀土/钴/锂）
    ▼
非洲资源竞争（场景8）+ 北极（场景6）+ 拉美锂三角
    │ 矿产贸易需要融资和货币结算
    ▼
全球金融体系（场景10）——美元/人民币结算竞争
    │ 金融实力决定财政空间
    ▼
美国财政能力 + 中国财政能力
    │ 财政空间决定全球投射能力
    ▼
台海（场景1）/ 南海（场景2）/ 印巴（场景5）/ 拉美（场景7）/ 乌克兰（场景3）
    │ 投射结果决定资源获取
    ▼
反向影响芯片联盟和技术供应链
    │
    └──→ 回到AI与芯片战争
```

## 关键假设检测

> 每个场景的分析必须严格区分"事实描述"和"主体叙事"

| 场景 | 事实（可观测） | 主体叙事（主体的自我描述） |
|------|-------------|----------------------|
| 拉美 | 美国对委内人拉采取军事行动；中国在拉美有24个一带一路签约国 | 美方称"确保西半球主导地位"；中方称"经济上的现实需要" |
| AI | 美国限制对华出口先进芯片；中国发布自研芯片 | 美方称"国家安全"；中方称"自主可控/效率革命" |
| 非洲 | 各方在非洲投资矿产和基建 | 美方称"供应链多元化"；中方称"发展合作" |

> ⚠️ 注意：场景分析中不应将"主体叙事"当作"客观事实"复述。应对"中国的'深度融入'叙事"和"美国的'供应链多元化'叙事"使用同等的分析距离。
