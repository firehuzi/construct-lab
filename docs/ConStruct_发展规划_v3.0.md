## 二、核心重新校准

### 原路线图的未覆盖方向

原路线图基于"构型"单一维度规划。以下新维度是后续发展中发现的，需要体现在新规划中：

1. **DNA矩阵（v5.0）** — 构型拆为D1(Identity)/D2(行为)/D3(稳定)/D4(依赖)四维。改变了建模方式。
2. **行为方法（M1-M8）** — 找到了8种基础行为方法，独立于构型。这为Phase 2的Action Predictor提供了核心输入。
3. **场景分层** — 发现10个场景不是平级的，而是形成引擎层→传导层→表现层三级网络。这个发现改变了耦合分析和传播链的逻辑。
4. **ICC框架** — 身份-能力耦合度，从状态变量升级为框架级变量。
5. **交互式诊断工具** — 原路线图没有"工具"这个类别。现在有了一个可用的诊断界面，可以作为后续功能的前端。

### 护城河重评

原路线图的护城河分析仍然成立：

```
主体档案库 → 2-3年积累 ← 已经领先
事件链库   → 2-3年积累 ← 框架已就位
信号规则库 → 2-3年积累 ← 未启动
预测数据集 → 3-5年积累 ← 未启动
```

但新发现的两个护城河需要加入：

```
行为方法库（M1-M8映射）    → 1-2年积累 ← 已部分完成
诊断工具迭代（用户测试数据）→ 持续 ← 刚起步
```

### Phase 2（2026年10月-2027年3月）：行为预测

**核心逻辑**：M1-M8方法 + C1-C5气质 + ICC = 行为预测的输入。不需要AI，基于规则即可。

#### 2.1 Action Predictor v1（基于规则）

输入：主体当前状态（构型 + 方法分布 + ICC + 外部压力）

预测规则示例：
```
IF 构型=冻结局 AND ICC↓ AND 外部压力↑
THEN 最可能行为 = 冻结局收紧（M5↑）
  次可能行为 = 寻求外部支持
  低概率行为 = 主动调整

IF 构型=交易式 AND 筹码↓ AND 对手施压↑
THEN 最可能行为 = 重新谈判（M2）
  次可能行为 = 强制选项（M1）
```

不需要ML，用嵌套规则表即可实现第一版。

#### 2.2 建立预测案例库

- 每周产出5-10个预测（基于当前事件）
- 记录：预测内容 → 实际结果 → 偏差分析
- 积累到200个预测后评估命中率
- 验证标准：>55%命中率（第一阶段）

#### 2.3 事件传播引擎 v1

基于三级场景网络结构：
```
引擎层变化 → 传导层 × 4（速率 = f(ICC, 构型)）
  → 表现层 × 4（响应幅度 = f(方法分布, 气质)）
    → 反馈回路（台海→引擎、中东油价→金融）
```

输出：P1-P4的自动化传播模拟（参数化版本）。

#### 2.4 诊断工具升级 v4.0

- 接入预测器（在工具中显示"当前预测"）
- 事件时间线组件
- 主体对比视图（并排比较两个主体）
- 导出功能增强（完整报告生成）

## 五、AI的角色（更新版）

原路线图的定位仍然正确：AI不是世界模型，是世界模型的加速器。

但基于当前实际，AI的角色可以进一步细化：

| 角色 | 当前 | Phase 1 | Phase 2 | Phase 3+ |
|------|------|---------|---------|----------|
| 档案建设助手 | ✅ 在用 | + | + | + |
| 框架逻辑校验 | 🟡 部分 | ++ | ++ | ++ |
| Signal初筛 | ❌ | + | ++ | +++ |
| 预测建议 | ❌ | ❌ | + | ++ |
| 自动标注 | ❌ | ❌ | + | ++ |
| 生成报告 | ❌ | ❌ | + | ++ |

原则：AI只做"有明确规则但量大"的事情（标注、初筛、格式化输出），不做"需要框架判断"的事情（构型分类、行为预测主逻辑）。
