# 04_ThinkTanks

> ★ **本目录当前【声明为空】。** 这份 README 说明它该装什么、为什么现在空、以及填它需要什么。
> 它是 S1.4 的产物：**让「空」变成被声明的、可机器查的状态**，而不是靠人记得它还没做。

## 该装什么

智库层：CSIS / RAND / Carnegie / Brookings / Chatham House 等**公开报告**的摘录与引用。

## 为什么现在空

从未开始。而它们是**次级来源**（在原方案的来源分级里该是 P1）。

## 填它需要什么

① 每份报告一条记录：机构 ／ 日期 ／ 标题 ／ URL ／ **它主张什么** ／ 与本框架的关系；② 用 `archive_source.py` 取证（它会判 `witness_type` 与 `tier`）。

## ⛔ 不许拿什么填

⛔ 不许只抄标题 —— 一条没有「它主张什么」的智库记录，对判断没有任何用处。

---

**审计**：`python -B construct-engine/cwkb_audit.py` 会把「声明为空」与「没人管的空」分开报。
