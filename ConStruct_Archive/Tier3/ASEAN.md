## 模块一：基础信息

| 字段 | 内容 |
|------|------|
| 主体名称 | 东南亚国家联盟（ASEAN / Association of Southeast Asian Nations） |
| 成立时间 | 1967年 |
| 成员国 | 10国（印尼、马来西亚、菲律宾、新加坡、泰国、文莱、越南、老挝、缅甸、柬埔寨） |
| **连续性类型** | **协调平台型**——不是超国家主体，不是军事联盟，是主权国家之间的协商框架 |
| **构型** | **协调平台**——比EU整合式松散得多。EU的共识=身份（修改共识=死亡）。ASEAN的共识=操作规则（不干涉内政+全体一致）——共识可以被绕过（通过"不讨论"问题，比如缅甸），但框架不能被废除 |
| **存在方式** | **"不选边=生存策略"**——在中美之间保持中立，同时和两大国都维持经济和安全关系。东盟的Identity不是"我们是谁"——是"我们是谁的邻居——但不想被任何一方吞并" |
| **核心恐惧** | **被迫选边**——一旦中美冲突升级到东盟不能"中立"的程度，东盟的生存策略就会破裂。成员国会被拉向不同的方向——平台可能分裂 |
| **身份一句话** | 我是一个由主权意识极强的国家组成的协商俱乐部。我们不需要"一体化"——我们的生存策略是"不选边"。只要中美都不强迫我们选边——我们就可以无限期地推迟回答"我们是谁"。 |


## 模块二：东盟悖论——不选边=生存，但选边压力在上升

东盟的核心策略是"对冲"：安全上有美国的存在（部分成员国的双边军事合作），经济上有中国的存在（RCEP+最大贸易伙伴），政治上保持"东盟中心性"（ASEAN Centrality——所有大国对话以东盟为中心平台）。

这个策略在1990-2020年间运作良好——中美关系是"竞争中有合作"，东盟可以从中获利。但2020年以后——中美从"竞争+合作"→"系统对抗"——东盟的"中间空间"在缩小。CN在南海的岛礁建设直接挑战越南和菲律宾的主权。US的印太战略要求东盟国家"选边"。东盟的"不选边"策略正在被两边的挤压所磨损。


## 模块三：构型——协调平台

| | EU整合式 | NATO整合式极端版 | **ASEAN协调平台** |
|---|---|---|---|
| 整合程度 | 高——超国家机构 | 高——美国主导 | **极低——主权国家的协商俱乐部** |
| 决策机制 | 共识（修改=死亡） | 一致（但美国是核心） | **共识+不干涉（共识可以被绕过）** |
| 约束力 | 有——法律约束 | 有——第五条 | **无——没有执行机制** |
| 最大的强项 | 制度深度 | 军事能力 | **灵活性——可以"不讨论"分歧** |
| 最大的弱项 | 制度僵化 | 美国依赖 | **不能做任何成员国反对的事** |
| 解体风险 | 有（共识破裂） | 有（美国撤出） | **低——因为它从未真正"整合"过** |

**ASEAN的精髓：** 它的弱项（不能强制成员国）恰好也是它生存的原因（没有任何成员国会觉得被东盟强迫做任何事）。比EU弱得多——但比EU稳定得多。
