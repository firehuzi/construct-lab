## ConStruct Lab · 框架笔记 #001

### 结构（Structure）的定位：一份总结

> 讨论日期：2026-06-19
> 相关概念：主体、策略空间、变量


## 一、核心命题

在ConStruct Lab框架中，结构不是独立于主体的“外部框架”，也不是主体身份的“附加维度”。

**结构的正确定位：**

```
结构 = 主体互动的结果（形成）
     → 主体未来行动的策略空间边界（约束）
     → 可被主体行动改变的变量（动态）
```


## 二、结构不是什么

| 误解 | 为什么不对 |
|------|----------|
| **结构是“先于主体存在的框架”** | 结构是主体互动的产物，不是先在的。北约不是先有章程才有的互动——是美欧互动形成了北约这个模式 |
| **结构是“给主体增加维度”** | 维度暗示结构是主体的一部分。但结构是主体之间的产物，不是主体的属性 |
| **结构是固定的“边界”** | 结构会变化。每次主体行动都可能改变结构的强度、方向、意义 |


## 三、结构是什么

**第一步：结构是主体互动的产物。**

结构不是外部“给予”的。它是多个主体在维持自身Identity的过程中，相互博弈、协调、冲突后形成的稳定模式。

```
美国想在欧洲保持安全影响力（Identity）
欧洲想被保护（Identity）
美欧互动 → 形成“美国主导、欧洲依附”的稳定模式
这个模式 = 北约
```

**第二步：结构是策略空间的边界条件。**

一旦结构形成，它就反过来约束主体的行动空间——但它不会“决定”主体的行为，而是划定一个边界。

```
北约形成后 →
美国不能单方面撤出（策略空间被约束）
欧洲不能立即自主防御（策略空间被约束）
```

**第三步：结构是可变的变量。**

结构不是固定的。主体的行动可以改变结构。

```
北约在冷战后几乎冻结 → 2022年俄乌战争激活 → 芬兰瑞典加入
第一岛链是美国建立的 → 中国海军成长改变了它的意义
```

> **结构是“冻结的行动模式”——它会在新的行动中重新融化、重塑。**


## 四、三个关键特点

### 1. 结构对不同的主体有不同的含义

| 结构 | 对中国的含义 | 对美国的含义 | 对日本的含义 |
|------|------------|------------|------------|
| 第一岛链 | 需要突破的“锁链” | 需要加固的“防线” | 决定自身安全的“边界” |

### 2. 结构可以被“激活”或“冻结”

> 结构不是“一直存在”——它是被主体的行动“唤醒”的。北约在冷战后几乎沉睡，直到俄罗斯入侵乌克兰，它才被重新激活。

### 3. 结构是动态的

> 结构不是地图上的固定线条。它是动态的、可变的、被主体不断重塑的力场。


## 五、在ConStruct Lab框架中的位置

```
主体有 Identity（L2-L8）
    ↓
主体与其它主体互动
    ↓
互动形成稳定模式 = 结构（当前状态）
    ↓
结构成为后续互动的约束 = 策略空间边界
    ↓
主体在边界内选择行动（L9）
    ↓
行动改变结构（反馈回路）
    ↓
（循环）
```


## 六、一句话收束

**结构不是地图上的固定线条。它是动态的、可变的、被主体不断重塑的力场。它既是主体策略空间的边界，也是主体可以改变的对象。**
