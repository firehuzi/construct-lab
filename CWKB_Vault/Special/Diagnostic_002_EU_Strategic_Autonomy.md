## I · Identity（主体身份定位）

### EU

| 维度 | 定位 | 依据 |
|------|------|------|
| L2 连续性类型 | **秩序型** | 认同围绕"欧洲秩序"而非单一民族。EU的存在=秩序的存在，秩序崩解=EU死亡 |
| L2 构型 | **整合式** | 28国共识=秩序维持方式。整合不是政策选择，是身份定义 |
| L3 存在方式 | **"维持高福利文明秩序=维持自己"** | 社会契约不是政策，是身份。福利体系崩解=身份崩解 |
| L4 建构来源 | 战后和平+一体化成功+规则主导 | "我们通过共识和规则成功了"——这个叙事定义了"我们是谁" |
| L5 维持机制 | **共识机制+规则制定+财政再分配** | 28国一致同意才能行动——这不是效率选择，是身份执行方式 |
| L6 秩序价值 | **共识=合法+规则=秩序+福利=承诺** | 三个价值是身份的三根柱子，任何一根断了=秩序崩解 |
| L7 他者系统 | **三重他者结构** | ①俄罗斯=否定性锚点（不可整合的威胁，激活"必须防御"的恐惧）②美国=肯定性锚点（不可脱离的秩序保障，提供安全+规则基础）③中国=交易性他者（重要贸易伙伴+系统性竞争者，不能脱离也不能整合） |
| L8 创伤→恐惧 | **碎片化** | 核心恐惧不是"被入侵"，不是"被打败"，是**"秩序崩解——成员国脱离、社会契约断裂、共识机制失效"** |

**身份一句话：** 我是一个共识驱动的文明秩序体。我的存在方式是28国一致同意。碎片化=死亡。

### 为什么"战略自主"对EU的Identity是一个悖论

战略自主需要什么？——**独立决策、独立行动能力、独立资源动员**。

EU的Identity是什么？——**28国共识驱动、整合式秩序、他者依赖（美国=肯定性锚点）**。

这两者之间存在一个结构性矛盾：

```
战略自主的核心要求：独立快速决策
EU Identity的核心执行方式：28国一致同意

战略自主的核心要求：独立行动能力
EU Identity的核心依赖：美国提供安全保障（肯定性锚点）

战略自主的核心要求：独立资源动员
EU Identity的核心约束：各国财政自主（欧盟不能强制国防预算统一）
```

**自主需要的每一项能力，EU的Identity都在阻止它获得。** 这不是意愿问题，不是资金问题——这是Identity的结构性悖论。

## P · Purpose（存在目的诊断）

EU的终极目的不是"安全"或"利益最大化"——是**维持身份定义的存在方式**。

```
EU终极目的：维持高福利文明秩序的完整
├── 不只是"活下来"，而是"以共识+规则+福利的方式活下来"
├── 如果安全自主需要牺牲共识机制 → Identity阻止
├── 如果安全自主需要牺牲福利支出 → Identity阻止
└── 如果安全自主需要牺牲他者依赖（脱离美国） → Identity犹豫

具体恐惧优先级：
① 碎片化（成员国脱离） > 
② 社会契约断裂（福利崩解） > 
③ 被入侵（俄罗斯威胁）

EU宁愿"不自主+不碎片化"，也不愿"自主+碎片化风险"
→ 因为碎片化=死亡，不自主只是"不舒服"
```

## S · Strategy Space（策略空间计算）

### 因果链第一步：Identity解释环境（已在DEL环节完成）

### 因果链第二步：Identity定义能力可动员范围

**EU客观资源 → Identity解释 → 可动员能力**

```
EU客观资源：
├── 市场：统一大市场 ✓ 完全可动员（这是Identity的核心资产）
├── 规则制定：标准/法规/数据保护 ✓ 完全可动员（规则=Identity执行方式）
├── 财政再分配：结构基金/农业补贴 ✓ 可动员（但各国自主限制了规模）
├── 国防预算：各国总和已达€800B级 ⚠ 可动员但碎片化（27国各自决定）
├── 国防工业：空客/达索/莱茵金属 ⚠ 部分可动员（但产能不足+碎片化）
└── 军事力量：无统一军队 ✗ 不能独立动员（NATO框架+美国保障）

→ Identity解释：
  规则制定权=核心身份 → 完全可动员
  市场整合=核心身份 → 完全可动员
  军事力量=不是核心身份 → 依赖肯定性锚点（美国） → 不能轻易自主动员
  国防预算=各国自主=尊重各国主权=共识机制的体现 → 不能强制统一

→ 策略空间上限：在规则/标准/市场领域极大
→ 策略空间下限：在军事/安全领域极小
→ 矛盾：自主最需要的领域（军事）=Identity最不允许自主的领域
```

### 因果链第三步：策略空间边界计算

**EU战略自主的四条路径：**

```
路径A：完全战略自主
├── 独立军队 ✓？ → 需要27国同意 → Identity阻止（各国军事主权）
├── 独立核威慑 ✓？ → 只有法国有 → 其他26国不参与 → 碎片化
├── 独立情报体系 ✓？ → 需要脱离美国体系 → Identity犹豫（肯定性锚点）
├── 独立国防工业 ✓？ → 需要10年+€50B/年 → 可以但需要共识支持 → Identity阻止（各国优先级不同）
└── → Identity约束：完全自主需要打破共识机制 → 打破共识=Identity崩解
→ ✗ 逻辑上不可能

路径B：选择性自主
├── 规则自主 ✓ → 已经实现（数据保护/碳交易/数字市场法案）
├── 经济自主 ✓ → 已经实现（统一大市场/贸易协定自主）
├── 能源自主 ⚠ → 正在进行（可再生能源转型+Buy European）
├── 军事自主 ⚠ → 部分进行（SAFE+PESCO+联合装备研发）
├── 安全自主 ✗ → 仍完全依赖NATO/美国
└── → Identity约束：选择性自主不需要打破共识 → 但军事自主部分仍然卡在共识上
→ ✓ 部分可能，但"自主"的部分恰好是不需要自主的部分（规则/经济），需要自主的部分（安全）做不到

路径C：增强依附
├── 深化NATO ✓ → 最低摩擦力路径 → 但美国正在撤
├── 增加美制装备采购 ✓ → 波兰已经在做 → 但Buy European政策正在限制
├── 接受美国主导的安全架构 ✓ → Identity允许（肯定性锚点）
└── → Identity约束：增强依附不打破共识 → 但外部条件正在消失（美国转向）
→ ✓ 矖石正在松动——依附的条件（美国保障欧洲安全）正在被美国自己削弱

路径D：碎片化自主
├── 法国推动自主联盟 ⚠ → 法德西意可能形成"核心欧洲"
├── 波兰/东欧继续依附美国 ⚠ → 安全优先
├── EU正式分裂为"自主核心"+"依附外围" ✗ → Identity阻止（碎片化=死亡）
└── → Identity约束：碎片化=EU死亡 → 任何导致分裂的方案都不被Identity允许
→ ✗ 逻辑上不可能（碎片化=Identity最恐惧的结果）
```

### 策略空间对比

```
路径A（完全自主）：✗ 逻辑不可能 —— 需要打破共识机制=Identity崩解
路径B（选择性自主）：⚠ 部分可能 —— 自主的部分不需要自主，需要自主的部分做不到
路径C（增强依附）：✓ 过去可行，现在松动 —— 依附条件正在消失
路径D（碎片化自主）：✗ 逻辑不可能 —— 碎片化=Identity最恐惧的死亡方式

→ EU的策略空间只剩路径B和路径C的混合
→ 但B的自主要素受共识约束，C的依附条件正在消失
→ EU正在两条路同时走，两条路同时变窄
```

### Strategy Selection机制

**为什么EU选了路径B+C混合而不是纯自主或纯依附？**

- **精英结构**：布鲁塞尔精英=共识机制的执行者 → 自主需要打破共识 → 精英利益绑定在共识机制上 → 选B+C混合=最低共识摩擦力
