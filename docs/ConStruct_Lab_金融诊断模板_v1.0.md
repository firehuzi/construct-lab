# ConStruct Lab 金融诊断模板

> 版本：v1.0 ｜ 基线：2026-07-29
> 定位：将 ConStruct Lab 的结构诊断方法论（主体→结构→约束→叙事→认知坍塌）映射到金融市场事件分析。原型案例：2026 年 7 月韩国 AI 半导体泡沫崩盘（SK海力士/三星，36 万杠杆账户强平）。
> 适用场景：市场泡沫→崩盘、板块轮动踩踏、叙事驱动的资产价格崩塌。

---

## 0. 核心原则

**不作阴谋假设。** 不判断"谁在割谁"。分析的是：一个系统如何被外部冲击触发，然后通过内部结构完成自我毁灭。

> 外部冲击只是输入变量，真正决定灾难规模的是内部叙事、身份认同、杠杆结构和反馈机制形成的自激系统。

---

## 1. 诊断框架：六步模型

### L1 — 表层事件（Surface Event）

**传统财经分析停留在这里。**

| 事件要素 | 填写 |
|---|---|
| 触发价格/指数 | （例：KOSPI/KOSDAQ 单日跌幅） |
| 触发主体/资产 | （例：SK海力士 / 三星电子） |
| 表面原因 | （例：财报不及预期、AI 芯片预期下调） |
| 资金面异动 | （例：外资净卖出 X 亿韩元） |
| 杠杆数据 | （例：X 万个账户触发保证金追缴 / 强平） |

**判断门槛**：如果分析到此为止，结论只会是"财报不好所以跌"——这是描述，不是诊断。

---

### L2 — 主体层（Actors）

**不是简单二分（散户 vs 机构），是按"资金-权力-信息"梯度分层。**

```
┌─────────────────────────────────────────────┐
│  全球资金（寻找拥挤交易、重新配置风险暴露）    │
│         ↓                                    │
│  韩国机构（国内资金池、做市责任）             │
│         ↓                                    │
│  券商系统（保证金规则执行·风险传导机器人）     │
│         ↓                                    │
│  杠杆散户（身份参与 > 投资行为）              │
│         ↓                                    │
│  AI 产业叙事（非人格化主体·自激循环）          │
└─────────────────────────────────────────────┘
```

#### 主体诊断卡（每事件填写）

| 主体 | 身份驱动 | 行为逻辑 | 脆弱点 |
|---|---|---|---|
| **散户** | "X 时代参与者"（身份参与） | 错过 X → 不能再错过 Y → 杠杆上车 → 不卖 | 身份崩塌比亏钱更难承受 |
| **全球资金** | 寻找流动性 / 降低风险暴露 | 寻找谁必须卖，不是谁想卖 | 拥挤交易退出→踩踏 |
| **券商系统** | 风险传导机器人（非人格） | 价格↓ → 保证金不足 → 自动卖出 → 价格↓ | 自动化→无人工制动 |
| **叙事本身** | 自激循环（非人格化主体） | 价格上涨→证明叙事正确→更多资本→上涨 | 一个负面信号可触达全链断裂 |

---

### L3 — 叙事系统（Narrative System）

**价格不是因为 DCF 计算便宜才涨——是因为叙事。**

| 叙事组件 | 填写 |
|---|---|
| **宏观叙事** | （例：AI 革命 / 绿色转型 / 元宇宙 / 去中心化金融） |
| **国家/产业身份叙事** | （例：韩国 AI 半导体全球核心 / 中国新能源龙头） |
| **自激循环证据** | 价格上涨 → 证明叙事正确 → 媒体/分析师强化 → 更多资本进入 |
| **叙事锚点（锚）** | 市场最怕被打破的一个问题（例："韩国是不是 AI 新时代赢家？"） |

**关键判断**：叙事锚点被打碎时，不是"估值回归"——是**身份崩塌**。下跌幅���不由 PE 决定，由叙事破裂的裂缝宽度决定。

---

### L4 — 脆弱点（Trauma Anchor）

**这个系统最害怕什么？**

| 维度 | 填写 |
|---|---|
| **市场锚定心理** | 不是问"X 公司今年赚多少钱"，而是问"X 国家/产业是不是新时代赢家" |
| **脆弱传导链** | 企业问题 → 产业问题 → 国家竞争问题 → 未来身份问题 |
| **脆弱放大器** | （例：高杠杆、叙事集中度、外资占比、保证金自动化程度） |
| **触发信号** | （例：一个普通财报不及预期 → 被翻译成产业/国家/身份危机） |

---

### L5 — 认知坍塌路径（Cognitive Collapse Path）

**从多种未来可能性压缩到唯一结果的过程。**

```
（初始）N 种未来可能性
         │
         ↓
      N-2  宏观叙事继续强化
         │
         ↓
      N-4  本国成为供应链核心
         │
         ↓
      N-8  "永远上涨"信念固化
         │
         ↓
      N-11  必须杠杆买入
         │
         ↓
      N-13  不能卖（身份锁定）
         │
         ↓
      N-14  一个负面信号
         │
         ↓
        1   强平
```

**核心洞察**：不是市场杀死投资者。是投资者过去建立的未来模型把自己锁死。

#### CEF 三阶段（Compression-Expression-Feedback）

| 阶段 | 定义 | 金融事件填空 |
|---|---|---|
| **Compression 压缩** | 复杂现实被压缩成一个简单叙事 | 例：AI 产业周期/半导体库存/全球利率/企业盈利 → 压缩成"AI 牛市来了，韩国必须赢" |
| **Expression 表达** | 叙事通过市场价格表达自己 | 例：股票上涨 → 上涨反过来证明叙事正确 |
| **Feedback 反馈** | 表达创造更多压缩 | 例：上涨 → 更多杠杆 → 更多散户 → 更高集中度 → 系统更脆弱 |

---

### L6 — 结构诊断结论（Diagnostic Output）

**不做预测。只诊断。**

| 诊断维度 | 填写 |
|---|---|
| **是否会崩？** | 不是关键问题。关键问题是：**系统已经脆弱到了什么程度？** |
| **脆弱度量** | （高杠杆倍数 / 叙事集中度 / 保证金自动化程度 / 外资占比） |
| **触发条件** | （一个普通负面信号是否被翻译成身份危机？） |
| **非人格暴力来源** | 哪些自动机制（券商保证金/算法交易/风险模型）会在没有人决策的情况下完成连锁反应？ |
| **外部冲击的角色** | 不是肇事者——是**利用了一个已经高度脆弱的系统**。真正完成毁灭的是系统自身。 |
| **可引用的一句话诊断** | （例：华尔街可能利用了一个已高度脆弱的系统，但真正完成猎杀的是系统自身。） |

## 2. 金融版独有贡献

> "券商作为风险传导机器人"是金融版 ConStruct Lab 的独有类别——地缘版里没有对等的结构开关。

| 金融版独有 | 地缘版对应（近似） |
|---|---|
| 保证金自动化强平 | NATO 第五条触发机制 |
| 算法交易的踩踏反馈 | 危机升级→媒体循环→公众恐慌 |
| 风险模型自动调仓 | 常任理事国否决权（自动阻断机制） |
| 衍生品瀑布效应 | 核威慑链（连锁触发） |

## 3. 快速诊断清单（一页版）

每次金融事件填入下表即可产出初步诊断：

| 层 | 检查项 | 填空 |
|---|---|---|
| L1 事件 | 触发资产/指数 + 杠杆账户数 | |
| L2 主体 | 分层：全球资金→本国机构→券商→散户→叙事 | |
| L2 券商 | 是否存在"风险传导机器人"（保证金自动平仓/算法踩踏）？ | |
| L3 叙事 | 上涨背后的宏大叙事是什么？叙事锚点是什么？ | |
| L4 脆弱点 | 市场最怕什么？一个普通负面信号能否被翻译成身份危机？ | |
| L5 认知坍塌 | 初始可能性数 → 压缩到 1 的路径（画衰减链） | |
| L5 CEF | Compression：什么被压缩？Expression：市场如何表达？Feedback：表达如何制造更多压缩？ | |
| L6 诊断 | 一句诊断语（外部冲击 + 内部自毁） | |

## 4. 模板维护

- **版本演进**：每次使用本模板完成一个真实金融事件分析后，回填发现的新模式、新类别
- **跨域校准**：与地缘版 L1-L10 诊断 schema 保持可对话——金融版 L2（主体层）≈ 地缘 L1（行为主体），金融版 L4（脆弱点）≈ 地缘 L8（创伤系统）
- **垂直化**：本模板为金融垂直专用。若套用到科技产业/组织制度/社会结构等垂直，需重写主体分层和脆弱点定义
