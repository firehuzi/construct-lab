## 模块一：基础信息

| 字段 | 内容 |
|------|------|
| 主体名称 | 石油输出国组织（OPEC / Organization of the Petroleum Exporting Countries） |
| 成立时间 | 1960年（巴格达会议） |
| 成员国 | 13国（核心：沙特、伊拉克、伊朗、科威特、阿联酋、委内瑞拉等） |
| OPEC+ | 13 OPEC国 + 10个非OPEC产油国（俄罗斯、哈萨克斯坦等）——2016年形成 |
| **构型** | **卡特尔**（经济学术语，不是政治构型）——通过产量配额影响油价——但成员国的作弊动机永远大于遵守动机 |
| **存在方式** | **"每一次OPEC会议决定产量=一次对现实的妥协"**——OPEC的存在价值是"我们能影响油价"——但每次会议都暴露了"我们多影响不了" |
| **核心恐惧** | **全球石油需求峰值已过——或成员国作弊使配额系统崩溃**——二者任一发生，OPEC的存在理由就消失了 |
| **身份一句话** | 我是世界上持续时间最长的合法卡特尔。我的存在本身就是一个悖论——成员国加入我以维持高油价，但每个成员国的最大利益是作弊多产油，让其他成员国减产来维持油价。 |


## 模块二：OPEC的悖论——卡特尔固有的囚徒困境

每个成员国的个体最优策略是：其他国家减产（推高油价）→ 我偷偷增产（以高价卖出更多油）。如果所有成员国都这样想——油价会崩溃。如果所有成员国都遵守配额——油价维持高位——但每个成员国都有作弊的动机。

**沙特是OPEC的"最后减产者"：** 当油价下跌时，沙特承担了最大的减产份额（因为它需要最少的石油收入来平衡预算——讽刺性地说，沙特的财政平衡油价是~$80，而其他成员国的财政平衡油价更高）。沙特在OPEC中的角色和美国在NATO中的角色相像——它是"最后买单的人"。这是沙特的交易式Identity的延伸——"我付钱让别人遵守规则"。


## 模块三：OPEC的黄昏——不是今天，但在地平线上

**三重压力：**
- **全球能源转型：** 电动汽车+可再生能源——任何每年替代200万桶/日石油需求的增长，都在削弱OPEC的长远存在意义
- **US页岩油：** 2010年代的页岩革命创造了OPEC之外的巨大产量——OPEC不再垄断全球石油供给
- **OPEC+内部的张力：** 俄罗斯在OPEC+中——但俄罗斯需要的是高价油来资助乌克兰战争——它的减产动机和OPEC成员国的作弊动机互相拉锯
