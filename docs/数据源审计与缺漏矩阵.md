# ConStruct Lab 数据源审计与缺漏矩阵

> 目的：在动手做可视化层之前，先把「数据从哪来」理清楚——按系统自身的 **8 结构域 + 主体域** 审计每个域的权威源、获取方式、时间粒度、保真适配度，并标出真缺口。
> 审计基线：2026-07，基于各数据集稳定公开状态。WebSearch 不可用时的核实以一手机构官网为准，逐源线上核验待补。

### MINERAL 关键矿物域
| 项 | 内容 |
|---|---|
| 权威源 | **USGS Mineral Commodity Summaries（MCS）**——年度 XLSX/PDF，~90 矿物，含「净进口依赖度」「单一来源依赖>25%」。**这是结构诊断金矿：依赖=约束** |
| 增强源 | Critical Minerals MCP（Apify，付费）——HHI 集中度 / 地缘脆弱性 / 替代就绪度评分 |
| 状态 | **部分**：USGS 是核心，无 API 需本地攒年；公司级产量归 SUPPLY |
| 缺 | 实时价格（归 COMMOD）、亚国家储量、跨年时序库（需本地累积 MCS 多年份） |
| 保真 | USGS 一手政府源，直接入 Knowledge 层 |

## 三、World Bank / IMF 专项评估（结论：权威宏观源，保留）

| 源 | 能给什么（独有价值） | 定位 |
|---|---|---|
| World Bank | WDI（宏观年度）、**WGI 治理指标**（话语权/政治稳定/政府效能/法治/腐败控制——制度质量与结构韧性直接量化）、WITS（贸易，基于 Comtrade） |
| IMF | IFS（宏观/汇率/储备）、**DOTS/BOPS 外部部门**（国际储备/外债/经常账户——外部脆弱性=结构约束）、WEO（世界经济展望） |

**裁定（用户 07-29 修正）：保留为权威宏观源，进核心数据清单，分层使用。**
1. 它们是**一手权威机构发布**，与保真契约不冲突，只是粒度宏观、滞后——定位为「宏观背景层 / 归一化层」，而非「细粒度事件源」；
2. **WGI 治理指标**可校准八维诊断的「维持机制 L5 / 秩序价值 L6」，**IMF 外部部门数据**可校准「行为约束」——这是 FRED / OWID 补不齐的独有价值；
3. 细粒度事件（冲突/贸易流/矿物依赖）仍直连 UCDP / Comtrade / USGS；宏观背景与归一化用 WB/IMF；
4. 二者在 `join-key ontology` 下通过 canonical actor 与各领域汇聚。

→ **与白皮书一致**：WB/IMF 不移除，作为权威宏观源保留。

## 四、跨域真缺口（比单域缺源更致命）

1. **跨域连接键 / 本体（join-key ontology）**——各域国家码不同（ISO-3 vs COW vs HS vs 商品码 vs **WB/IMF 国家码**）。需建 **canonical actor → 多码映射**，才能把「矿物依赖 + 供应链流 + 大宗价 + 金融暴露 + WB/IMF 宏观」接成同一张图。这是结构胶水，当前缺失。
2. **时间一致性**——大多为年度，需定义统一时间粒度（年）并本地累积多年份，否则跨域时序对不齐。
3. **域定义缺口**——AI / 社会 / 气候 三域的数据源映射尚未定义或模糊，需先 scope 再接。

## 六、建议落地顺序

1. **先固化 MINERAL 域（USGS MCS）**——数据最权威最干净，且「矿物依赖=国家结构约束」与八维诊断契合度最高，是最优垂直切片。
2. **建 join-key ontology**——canonical actor → (ISO-3 / COW / HS / 商品码) 映射表。
3. **补 SUPPLY（Comtrade API）**——做贸易流向弧线（deck.gl ArcLayer）。
4. **AI / 社会 / 气候** 三域先 scope 再接源（AI 以策展为主，社会先定域，气候用 OWID 快进）。
5. **WB/IMF 仅作宏观归一化备用**，不进管线。
