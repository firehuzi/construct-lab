# 制裁

## 定义

> [!definition] 核心定义
> 一国或多国通过限制经济/金融/技术交流，迫使目标主体改变行为的强制手段。本质是交易式权力的延伸——切断连接以施加代价。

## ConStruct映射

| 层级 | 映射 |
|------|------|
| L2 | 交易局——制裁是交易的中断，非秩序的否认 |
| L3 | 代价施加机制——行为改变=代价>收益 |
| L5 | 制裁发起/承受的精英计算 |
| L6 | 制裁的法律制度化（OFAC、EU制裁清单） |
| L7 | 制裁=他者关系的强制重定义；被制裁=被排除出秩序 |
| L8 | 制裁能否改变Identity——通常不能（俄罗斯反更强） |

## 观察指标

1. **制裁广度**：涉及多少经济部门
2. **制裁深度**：是限制性还是全面性
3. **制裁联盟**：单边vs多边——多边=秩序行为，单边=交易行为
4. **反制裁能力**：目标是否有替代网络
5. **制裁疲劳**：发起方持续意愿

## 典型案例

| 主体 | 表现 | 备注 |
|------|------|------|
| 俄罗斯 | 被全面制裁但经济未崩溃 | 制裁≠行为改变（Identity结构抵抗） |
| 伊朗 | 被制裁40年，行为未根本改变 | 互锁式Identity——让步=身份否定 |
| 朝鲜 | 最严厉制裁，核武未放弃 | 自主局——核武=生存=Identity核心 |

## 反例

| 主体 | 为什么不算 | 边界条件 |
|------|-----------|---------|
| 南非（1980s） | 制裁促成种族隔离终结 | 制裁有效——Identity（种族隔离制度）可被修正 |
| 利比亚 | 制裁促成放弃WMD | 交易式——卡扎菲做交易，非Identity让步 |

## 关键诊断

> [!warning] ConStruct核心判断
> 制裁改变行为，不改变Identity。制裁越深入，Identity抵抗越强。制裁有效的唯一条件：目标Identity的结构性让步≠身份否定（交易式可以，互锁式不行）。
