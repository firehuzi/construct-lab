# 安全依赖

## 定义

> [!definition] 核心定义
> 一个主体在安全领域无法自主行动，必须依赖外部保护者的状态。依赖不是软弱——是Identity结构的选择或冻结条件。

## ConStruct映射

| 层级 | 映射 |
|------|------|
| L2 | 依附局——安全依赖是连续性维持的外部条件 |
| L3 | 保护换取机制——安全外包→自主性让渡 |
| L5 | 精英对依赖的态度——依附精英vs自主精英 |
| L6 | 依赖的制度化（驻军协议、安保条约） |
| L7 | 依赖=他者承认的极端形式——保护者=最高权威 |
| L8 | 依赖是暂时的还是永久的——日本=永久冻结，德国=逐步解冻 |

## 观察指标

1. **外部军事存在**：驻军规模和持续时间
2. **自主军事能力**：能否独立作战
3. **保护者可靠性**：保护者是否有能力和意愿履约
4. **依赖成本**：让渡了什么自主性
5. **解冻信号**：依赖是否在减弱

## 典型案例

| 主体 | 依赖形式 | 解冻趋势 |
|------|---------|---------|
| 日本 | 美日安保+驻军 | 缓慢解冻——5个行动全指向扩张（↑） |
| 德国 | 北约+美军核共享 | 缓慢解冻——€800B特别基金 |
| 韩国 | 美韩同盟+驻军 | 有限解冻——自主核武装讨论 |
| 新加坡 | 无正式依赖 | 无——靠否定自身+多方平衡 |

## 反例

| 主体 | 为什么不算 | 边界条件 |
|------|-----------|---------|
| 法国 | 退出北约军事一体化 | 不依赖——自主=Identity核心 |
| 印度 | 不结盟 | 不依赖——战略自主=Identity |

## 关键诊断

> [!warning] ConStruct核心判断
> 安全依赖的解冻不是线性的——冻结局的微调（日本↑）vs依附局的解冻（德国？）是不同过程。冻结局可以缓慢扩张策略空间而不触发Identity危机；依附局的解冻需要新的Identity定位。
